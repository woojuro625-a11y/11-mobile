베이지 연필 스케치 → 흑백 대시보드 → 검정 민트 3막, FIG/BEAT 표시, 120BPM 박자. 예시: 

폴더 구성: (장면), (기록 데이터), (캡처·사진·캐릭터), (prep_run.py 데이터 추출, breaks.py 급수·휴식 감지, sfx16.py 효과음, render.js 렌더, fonts6.py 폰트)

현재본: `v13/` (렌더 결과 `Downloads/러닝스토리_v13_20261124.mp4`). v12 + 급수·휴식 감지. 이전: v10(사진 없음), v11(사진 인트로 별도 장면)

## 매번 받는 입력
1. 가민 커넥트 원본 데이터 파일 (FIT, zip 그대로 가능)
2. 가민 커넥트 앱 기록 화면 캡처 1장
3. (선택) 오늘의 사진: 배경 사진이나 러닝크루 발 모은 사진 등. 영상 맨 앞 '오늘의 사진' 장면에 들어간다 (여러 장이면 `PHOTOS`에 추가해 짧은 슬라이드)
4. (채팅으로) 활동 제목, 메모, 후기 문장 — FIT 파일에는 제목과 메모가 들어 있지 않다

## 규격
- 1080×1920 세로, 60fps, 30초, H.264 + AAC
- 음악 없음 (사용자가 직접 넣음), 효과음만. 효과음은 필요한 곳마다 넣되 볼륨은 작게 (피크 -12 dBFS 안팎)
- 효과음만 담긴 WAV도 함께 전달
- 결과물은 `Downloads/`에 저장하고 파일 카드로 전달

## 구성 (60박, 120BPM)
| 시간 | FIG | 내용 |
|---|---|---|
| 0~4.8초 | 01 오늘의 기록 | 사진 + 가민 캡처를 한 장면으로: 사진 전체 화면(제목·메모·날짜, 발 사이 스타 러너) → 사진이 흐린 배경으로 물러나고 제목은 머리글로 → 캡처 카드가 날아와 착지 → 지도로 확대 → 기록 숫자로 이동 → 전체로 빠짐 → 종이가 올라와 다음 장면 (캡처는 표시 없이 원본 그대로) |
| 4.8~8.6초 | 02 페이스 그래프 | 베이지 종이, 실제 페이스(기록 약 9초 이동평균)를 실제 거리 축 위에 점점 그려 나감 + 각 km 위 1km 평균 가로선(가장 빠른 주황 / 가장 느린 파랑), 순간 최고 페이스 점·표시, 빠른·느린 1km 차이, 한 줄 문구 |
| 8.6~13.6초 | 03 러닝 리포트 | 흑백 대시보드 + 색 포인트 (총 거리 주황, 달린시간 파랑, 평균페이스 초록, 평균심박수는 존 색, 가장 빠른 구간 주황, 가장 느린 구간 파랑). 다 채워진 뒤 멈춰서 읽을 시간 → 커서가 "심박" 탭 → 심박 링 |
| 13.6~18초 | 04 심박 존 | 가민 "심박존별 시간" 형식 목록(5존→1존→존 미만, 범위·시간·%) + 존 색 띠 그래프. "밤" 토글로 검정 전환 |
| 18~20초 | 05 숫자 | 민트 박스 숫자가 박자마다 바뀜 |
| 20~30초 | 06 완주 | 10초 반복: 와이어 지구본 + 기록 글자 링 + 기록 6칸 + 러닝 메모 칸 |

삭제된 장면(다시 넣지 않음): 러닝 코스 지도 장면, 분당 심박수 3D 장면, 캡처 위 동그라미

## 문구·표기 규칙
- 라벨은 한글: 총 거리, 달린시간, 평균페이스, 심박수, 평균심박수, 최대심박수, 칼로리
- 문장에 쉼표·마침표를 쓰지 않는다 (숫자의 소수점은 예외)
- 심박 존은 가민 존 기준(FIT의 time_in_zone 경계값)으로 1~5존을 색으로 구분하고 글씨는 크게
- 급수·휴식(중간 멈춤) 감지: `breaks.py <fit> <data.js>`가 시계 일시정지, 10초 넘는 기록 공백, 15초 넘게 멈춰 있음, 45초 안에 20bpm 넘게 떨어졌다 다시 오른 심박을 찾아 `DATA.breaks`에 넣는다 (출발·도착 1분 제외). 있으면 심박존별 시간 그래프에 빗금 띠와 '급수 또는 휴식 n분 n초' 라벨, 위쪽에 주황 표시 '중간에 n번 멈춤'. 없으면 '중간 멈춤 없이 연속 달리기'. 미리보기 테스트는 페이지 주소에 `&testbreak=1`
- 심박수 숫자 색은 그 값이 속한 존 색으로 자동 지정 (1존 회색, 2존 파랑, 3존 초록, 4존 주황, 5존 빨강)
- 메모 칸: 머리줄 아래 구분선, 본문은 상자 가운데 정렬, 길면 글자 자동 축소
- 메모는 사용자가 가민에 쓴 줄바꿈을 그대로 지킨다 (`RUN.review`에 `\n`으로 줄 구분). 한 줄이 상자보다 길 때만 그 줄 안에서 줄바꿈

## 캐릭터
- 스타 러너 (스킬 `handdrawn-motion-video`의 `assets/starrunner` 모델 이미지)
- 주인공이 아니라 화면마다 작게 숨어 있는 이스터에그. 캐릭터 전용 효과음은 넣지 않는다

## 새 기록으로 만들 때 바꿔야 하는 곳 (`v10/story.html`)
- `INFO`: 제목, 메모, 날짜, 칼로리, 평균·최대 심박, 후기 문장
- 구간 그래프의 세로 범위(`spY`), 대시보드 막대 높이, 심박 링 길이: 해당 기록의 페이스·심박 범위에 맞춤
- 문구 "흔들림 없이 같은 리듬으로", "14초", "대부분 1존에서 숨 고르며 편안하게"는 이번 기록 기준이라 데이터에 맞게 다시 씀
- 캡처 이미지(`img/garmin.png`) 교체. 이번 캡처는 빨간 표시를 지우고 제목을 다시 써넣었으므로, 표시 없는 캡처면 제목 재작성 코드는 뺀다
- 데이터: `prep2.py`로 FIT → `data.js` 생성 (경로·심박·랩·존 시간)

## 새 기록 만드는 순서 (v14부터)
1. `python3 -I prep_run.py <FIT> <폴더>/data.js` — 경로·심박·랩(100m 미만 꼬리 랩 제외)·가민 존 시간·세션 요약(거리·시간·평균/최대 심박·칼로리·날짜)
2. `python3 -I breaks.py <FIT> <폴더>/data.js` — 급수·휴식 감지
3. `img/garmin.png`(캡처), `img/photo1.jpg…`(사진, 1080×1920으로 맞춤) 교체
4. `story.html`의 `RUN`만 고친다: 제목, 짧은 메모(머리글), 후기(review, 쉼표·마침표 없이), 사진 목록, 사진별 스타 러너 위치(photoEggs), 캡처 제목 덧칠 여부(capFixTitle)
5. 캡처 크기가 다르면 `CAP`(w,h)와 오프닝 카메라 `CAMK`(지도·메모·기록 숫자 위치) 확인
6. 자동으로 정해지는 것: 구간 그래프 범위·개수·라벨, 빠른·느린 차이, 구간 문구(SPLIT_LINE), 심박 존 문구(ZONE_LINE), 시간축, 대시보드 막대·표, 심박수 존 색
7. 효과음: `sfx14.py`의 구간 점 개수(NL)에 맞춰 시각 계산
