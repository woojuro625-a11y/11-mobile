# 9안 무인도 (노래 Shoes Back in the Box)

노래를 제목과 상관없이 소리로 분석해서 만든 양식. 처음에는 재즈 레코드 슬리브 컨셉이었으나 사용자 요청으로 **분위기 좋은 해변, 무인도에 표류한 스타 러너** 컨셉으로 바꿨다.
- 노래 분석: 약 84.7BPM의 여유 있는 그루브, G장조에 F 화음이 섞인 블루지하고 따뜻한 화성(G → Em → F → C, 한 마디에 한 화음), 박마다 짧게 끊어 치는 화음, 슬라이드 베이스, 아주 넓은 스테레오, 보컬 없음. 마디는 화음이 바뀌는 2.59초에서 시작(1마디 2.83초) — 따뜻하고 느긋한 해질녘 해변과 잘 맞음
- 배경(Figma AI로 만든 사진 두 장):
  - `img/beach.jpg`: 노을 진 무인도 해변(야자수, 뗏목, 모래에 반쯤 묻힌 병). 오프닝과 엔딩. 천천히 다가가고, 해 빛이 노래에 맞춰 숨 쉬고, 바다 위 반짝임, 하늘을 지나가는 갈매기, 위쪽은 글자용으로 살짝 어둡게
  - `img/sand.jpg`: 위에서 내려다본 모래사장(아래에 바다). 데이터 장면. 원래 있던 조개·유목은 글자와 겹쳐서 지웠다(같은 모래로 덮음). 야자수 잎 그림자가 흔들리고 아래 물가에서 파도가 들어왔다 나감
- 데이터는 무인도에서 찾은 것으로: 글자는 막대로 모래에 쓴 것처럼 파인 글씨(`sandTx`: 아래쪽 밝은 테두리 + 진한 홈), 가민 캡처는 병 속 편지 두루마리, 구간 기록은 유목 널빤지(길수록 빠름, 가장 빠름 불가사리·가장 느림 조개), 페이스 그래프는 모래에 막대로 그은 선(스퍼트 구간 산호색, 가장 빠른 순간 불가사리, 나무 팻말 카드), 심박존은 존 색 바다유리
- 장면 전환: 마디 첫 박마다 파도가 화면을 덮었다가 빠지면서 다음 장면이 나옴(`waveWash`), 그때 파도 소리
- 글꼴: 제목 Jua, 숫자 Fredoka(500·700), 손글씨(모래 글씨·메모) Gaegu 700, 작은 라벨 고운돋움. 얇은 펜 글씨(나눔손글씨 펜)는 모래 위에서 잘 안 읽혀서 쓰지 않음
- 스타 러너: 밀짚모자(빨간 띠)를 쓴 표류자(`island3d.js`). 기본 자세는 팔을 편하게 내림. 오프닝: 뗏목 옆에서 손 그늘로 바다를 살피다가 손을 흔들고 흔들흔들. 엔딩: 손 흔들기 → 흔들흔들 → 손가락 스냅 → 바다 살피기, 마지막 페이드아웃에 손 흔듦. **데이터 장면에서는 이스터에그**: 물가를 따라 작게 걸어가며 모래에 발자국을 남김(걷는 방향을 봄)
내용 규칙은 1안과 같다 (가민 캡처 원본, 실제 페이스, 한글 라벨, 쉼표·마침표 없음, 메모 줄바꿈 유지, 심박수 존 색, 1080×1920 60fps 30초, 22초부터 엔딩 전체 유지).

## 음악
- `python3 -I scripts/music_full.py 노래.wav music30.wav 임시.js first 84.69 2.593` — 곡의 처음부터 편집 없이 30초, 마지막 1초 페이드아웃
- 박자 격자 `beat.js`는 84.69BPM 고정 격자(첫 마디 2.593초)로 직접 쓴다:
```python
import json;b=60/84.69;d0=2.593-4*b
B=[[round(d0+k*b,4),k%4==0] for k in range(60) if 0<=d0+k*b<30]
open('beat.js','w').write('const BEATS='+json.dumps(B)+';')
```
- `python3 -I scripts/drums.py music30.wav beat.js drums.js`, `python3 -I scripts/bassenv.py music30.wav bass.js`
- 효과음 `python3 scripts/sfx_b9.py beat.js sfx.wav`: 장면이 바뀔 때 파도 소리, '완주' 나무 팻말 '툭', 병 편지 코르크 '뽁' / 피크 -17 dBFS

## 구성 (마디 기준, 1마디 2.83초)
| 시간 | 장면 | 내용 |
|---|---|---|
| 0~5.43초 | 해변 (노을) | 하늘에 '오늘의 러닝'·제목·산호색 메모 알약·날짜, 뗏목 옆 스타 러너가 바다를 살피다 손 흔듦, 사진 세 장이 폴라로이드처럼 모래 위에 떨어짐(손글씨 캡션) |
| 5.43~8.26초 | 가민 캡처 | 모래 위 병 속 편지 두루마리에 메모를 잘라낸 캡처 **전체 그대로**(확대·덧그림 없음), 왼쪽 유목 꼬리표 '지도' '제목' '기록'과 모래에 그은 화살표 |
| 8.26~12.51초 | 구간 기록 | 모래 글씨로 km와 기록, 유목 널빤지(밧줄 묶음)가 길이대로 놓임, 가장 빠름 산호색 글씨 + 불가사리, 가장 느림 조개. 아래 평균페이스와 빠른·느린 구간 차이 |
| 12.51~16.76초 | 페이스 그래프 | 모래에 막대로 그은 실제 페이스 선(막대가 선 끝을 따라감), 가장 빠른 순간이 나온 km를 산호색으로 비추고 천천히 그림, 선 위 불가사리 → 나무 팻말 카드(순간 최고·그 km 구간)가 장면 끝까지, 아래 평균·최고 페이스·총 거리와 구간 문구 |
| 16.76~19.60초 | 심박존별 시간 | 가민 순서(5존→존 미만) 존 색 바다유리 막대, 범위·시간·%, 평균·최대 심박수 크게(존 색), 가장 오래 머문 존, 중간 멈춤 여부 |
| 19.60~30초 | 해변 (노을) | 하늘에 제목, 나무 '완주' 팻말, 가운데 스타 러너, 나무색 반투명 판 위 기록 6칸, 병 속 편지 두루마리의 러닝 메모(줄바꿈 그대로, 스킬 `running-memo-emphasis`: 숫자 산호색 Fredoka + 연한 산호색 동그라미, 몸 상태 빨강 물결 밑줄, 다음 계획 청록 띠, 감정 청록 물결 밑줄, 핵심 진한 밑줄). 21.9초까지 모두 나오고 끝까지 유지 |

## 새 기록으로 만들 때
1. `prep_run.py`, `breaks.py`로 data.js / 캡처는 `cut_memo.py`로 메모를 잘라 `img/garmin.png`, `CAP.h` 확인 / 사진 `img/photo1~3.jpg`
2. `RUN`(제목·메모·후기·`reviewMarks`·사진 캡션) 수정
3. 노래가 같으면 `beat.js` `drums.js` `bass.js` 그대로
4. `python3 scripts/fonts_b9.py .` (먼저 `fonts/` 폴더) → `node scripts/render.js video 60 out.mp4` (3D라 WebGL 옵션 포함) → `sfx_b9.py`로 효과음 → `ffmpeg -i music30.wav -i sfx.wav -filter_complex "[0][1]amix=inputs=2:normalize=0,alimiter=limit=0.89" mix.wav` → 영상과 합치기
5. 확인: `../qc.sh out.mp4 qc폴더 940:560:70:1250 21 30`
