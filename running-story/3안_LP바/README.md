# 3안 LP 바 (음악 편집 + 박자 진행)

어두운 LP 바에 들어온 듯한 분위기의 양식. 1안·2안은 효과음만 넣고 음악은 사용자가 직접 넣지만, **3안은 사용자가 준 노래를 30초로 편집해 깔고 화면이 그 노래의 박자와 마디에 맞춰 넘어간다.**
내용 규칙은 1안과 같다 (가민 캡처 원본, 실제 페이스, 한글 라벨, 쉼표·마침표 없음, 메모 줄바꿈 유지, 심박수 존 색, 마지막 10초 반복, 1080×1920 60fps 30초).

## 음악 (예시: Pocketed Bars)
- `scripts/music_edit.py <노래.wav> music30.wav beat.js [드롭 a0 a1 b0 b1]`
  - 노래 앞부분 A(1.391~21.409초: 잔잔한 도입 + 비트 시작)와 끝부분 B(48.298~58.28초: 아웃트로)를 50ms 동일 전력 크로스페이드로 이어 정확히 30초
  - 이음새가 마지막 10초 반복 시작(약 20초)과 맞아 노래가 아웃트로로 넘어가는 순간 엔딩 카드가 열린다
  - 드롭(비트가 들어오는 순간)은 편집본 7.154초. 이 곡 기준 템포 약 108BPM, 한 박 0.557초, 한 마디 2.23초
  - 노래를 바꾸면 들어 보고 A·B 구간과 드롭 시각을 정해 인자로 넣는다. `beat.js`(박 시각과 마디 첫 박 표시)를 새로 만들면 장면이 자동으로 그 박자를 따른다
- 완성 영상 소리 = `music30.wav` + 효과음(`scripts/sfx_b3.py`, 피크 -15 dBFS로 노래 밑에 작게) → 리미터

## 구성 (박자 기준)
| 시간 | 장면 | 내용 |
|---|---|---|
| 0~7.15초 (잔잔한 도입) | 입장 | 네온 'LP Bar'가 깜빡이며 켜짐 + 'OPEN 19:24'(출발 시각) → 제목·메모·날짜 → 오늘의 사진이 폴라로이드로 떨어짐(손글씨 캡션, 사진 옆 스타 러너) → 레코드 슬리브가 올라오고 가민 캡처 카드가 슬리브에서 빠져나와 **전체로** 섬(확대·잘림 없음) → A1 지도·A2 제목·A3 기록 차례로 밝히기 → 카드가 빠지고 턴테이블 등장, 레코드가 미끄러져 올라가고 톤암이 움직여 바늘이 드롭 직전에 내려앉음 |
| 7.15~11.06초 (드롭) | SIDE A 트랙리스트 | 빛이 번쩍이며 턴테이블이 위로. 1km 구간을 트랙 A1~A8로 위에서 아래로 한 줄씩(8분음표마다 한 줄), 가장 빠름 주황·가장 느림 파랑 태그, 평균페이스와 빠른·느린 1km 차이 |
| 11.06~15.54초 (두 마디) | 페이스 그래프 | 턴테이블이 왼쪽 위 작은 레코드로. 실제 페이스(약 9초 이동평균)를 **한 박자에 1km씩** 웨이브처럼 그려 나감, 위쪽에 km별 페이스, 각 km 평균 점선, 선 끝을 달리는 스타 러너, 순간 최고 페이스 4'01" 표시, 평균·최고·거리, 구간 문구 |
| 15.54~20.02초 (두 마디) | 심박존별 시간 | 앰프 VU 미터: 1존~5존 LED 막대가 한 박자에 한 존씩 올라옴(존 색), 박자마다 맨 위 칸이 반짝, 존별 범위·시간·%, 존 미만, 평균·최대 심박수(존 색), 가장 오래 머문 존, 중간 멈춤 여부 |
| 20.02~30초 (아웃트로) | 엔딩 반복 | 네온 'Now Playing' + 곡 이름, 레코드가 돌아가는 턴테이블(라벨에 제목), 기록 6칸(크레딧), 러닝 메모를 손글씨 라이너 노트로(가민에 쓴 줄바꿈 그대로, 박자마다 한 줄씩), 턴테이블 구석의 작은 스타 러너(가끔 손 흔듦). 노래가 잦아들면 LP 잡음이 조금 올라옴 |

## 효과음 (`scripts/sfx_b3.py`)
도입부 LP 잡음, 폴라로이드 착지, 슬리브·카드 미끄러짐, 표시 클릭, 레코드 착지, 톤암, 바늘 내려앉는 소리, 장면 전환 바람 소리, 엔딩의 LP 잡음. 모두 노래 밑에 깔리도록 작게.

## 새 기록으로 만들 때
1. `python3 -I scripts/prep_run.py <FIT> data.js`, `python3 -I scripts/breaks.py <FIT> data.js`
2. 캡처에서 메모 본문을 잘라낸다: `python3 -I scripts/cut_memo.py <캡처> img/garmin.png <제목 줄 바로 아래 y> <거리 숫자 바로 위 y>` → `story.html`의 `CAP.h`를 새 높이로. 지도·제목·기록 밝히기 위치(`REG`)는 비율이라 비슷한 캡처면 그대로
3. 사진 `img/photo1.jpg…` 교체, `RUN`(제목·메모·후기·사진 캡션·곡 이름) 수정
4. 노래가 같으면 `beat.js` 그대로. 바꾸면 `music_edit.py`로 `music30.wav`와 `beat.js`를 새로 만든다
5. `python3 scripts/fonts_b3.py .` (새 글자가 생기면 글꼴 부분집합 다시)
6. 렌더: `node scripts/render.js video 60 out.mp4` → `python3 scripts/sfx_b3.py sfx.wav` → 노래와 효과음을 섞어 합치기
   `ffmpeg -i music30.wav -i sfx.wav -filter_complex "[0]aresample=48000[m];[m][1]amix=inputs=2:normalize=0:duration=first,alimiter=limit=0.89:level=false" mix.wav`
