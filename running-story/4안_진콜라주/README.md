# 4안 진(zine) 콜라주 (음악 편집 + 박자 진행)

노래 'Three Snare Cuts'에 맞춘 양식. 오려 붙인 종이, 찢어진 가장자리, 망점(하프톤) 사진, 테이프, 고무 도장, 굵은 글자의 스트리트 잡지 느낌.
3안처럼 노래를 30초로 편집해 깔고 화면이 박자와 마디에 맞춰 진행한다. 내용 규칙은 1안과 같다 (가민 캡처 원본, 실제 페이스, 한글 라벨, 쉼표·마침표 없음, 메모 줄바꿈 유지, 심박수 존 색, 마지막 10초 반복, 1080×1920 60fps 30초).

## 음악 (Three Snare Cuts)
- 약 112BPM, 킥이 마디 첫 박, 스네어는 2·4박. 도입 없이 처음부터 비트가 달린다
- `python3 -I scripts/music_edit.py 노래.wav music30.wav beat.js 0 3.228 17.02 42.5 58.8`
  - 4마디 프레이즈 경계끼리 이음: A 3.228~17.02초(두 박 못갖춤마디로 시작) + B 42.5~58.8초(마지막 프레이즈부터 곡 끝까지) → 30초
  - 이음새 13.79초 = 새 프레이즈 시작. 이 순간에 페이스 그래프의 마지막 1km 스퍼트 조명이 켜진다
  - 마디 첫 박 기준은 기본값 `kick`
- 소리 = `music30.wav` + 효과음(`scripts/sfx_b4.py beat.js sfx.wav`: 장면 전환 가위 소리 세 번, 종이 붙는 소리, 테이프, 도장 / 피크 -15 dBFS로 노래 밑에 작게) → 리미터

## 구성 (마디 기준, 장면 전환은 '세 번 자르기': 새 장면이 대각선 세 조각으로 16분음표마다 붙음)
| 시간 | 장면 | 내용 |
|---|---|---|
| 0~3.18초 | 표지 | 랜섬 노트식 '오늘의 러닝'(글자마다 다른 종이)이 박자마다 붙음 → 마디 첫 박에 제목 '회복조깅'과 형광펜 → 메모 띠(파란 종이) → 날짜 테이프 → 오늘의 사진 두 장을 망점 인쇄로(분홍·파랑), 손글씨 캡션, 사진 위 스타 러너 스티커 |
| 3.18~7.41초 | 가민 캡처 | 메모를 잘라낸 캡처를 **전체 그대로** 네 귀퉁이 테이프로 붙임(확대·덧그림 없음). 왼쪽에서 '지도'·'제목'·'기록' 꼬리표가 화살표로 가리킴 |
| 7.41~11.66초 | 구간 기록 | 1km부터 8km까지 위에서 아래로 찢은 종이 띠(길수록 빠름), 가장 빠름 분홍·가장 느림 파랑, '가장 빠름'·'가장 느림' 고무 도장, 평균페이스와 빠른·느린 1km 차이 |
| 11.66~15.88초 | 페이스 그래프 | 모눈종이에 실제 페이스(약 9초 이동평균)를 반 박자에 1km씩. 이음새(13.79초)에서 최고 페이스가 나온 km만 분홍 형광펜으로 비추고 두 박자에 걸쳐 그림 → 최고 지점 점 + 분홍 스티커 '마지막 1km 스퍼트 / 순간 최고 4'01" / 8km 구간 4'58"'이 장면 끝까지 남음. 평균·최고·거리, 구간 문구 |
| 15.88~20.13초 | 심박존별 시간 | 가민 순서(5존→존 미만)로 존 색 종이 띠, 범위·시간·%, 평균·최대 심박수(존 색), 가장 오래 머문 존, 중간 멈춤 여부 |
| 20.13~30초 | 뒤표지 반복 | 랜섬 '오늘의 러닝', 제목, 빨간 '완주' 도장, 기록 6칸 카드, 공책 한 장에 러닝 메모(가민 줄바꿈 그대로, 괘선에 맞춰 가운데 정렬, 한 줄이 길면 글자를 먼저 줄임), 흐르는 노란 테이프, 귀퉁이 스타 러너(가끔 손 흔듦) |

## 새 기록으로 만들 때
1. `python3 -I scripts/prep_run.py <FIT> data.js`, `python3 -I scripts/breaks.py <FIT> data.js`
2. 캡처: `python3 -I scripts/cut_memo.py <캡처> img/garmin.png <제목 줄 바로 아래 y> <거리 숫자 바로 위 y>` → `story.html`의 `CAP.h`
3. 사진: `python3 -I scripts/halftone.py <사진> img/ht1.png '#1C1440' '#FF9EC0'`, 두 번째는 `img/ht2.png '#101D4A' '#9FC2FF'` (어두운 밤 사진은 자동으로 밝게 맞춤)
4. `RUN`(제목·메모·후기·사진 캡션·호수) 수정
5. 노래가 같으면 `beat.js` 그대로. 바꾸면 `music_edit.py`로 새로 (장면 시작은 `nearDB()`로 가장 가까운 마디 첫 박에 자동으로 맞춤)
6. `python3 scripts/fonts_b4.py .` → `node scripts/render.js video 60 out.mp4` → 효과음 만들고 노래와 섞어 합치기 (3안 README의 ffmpeg 명령과 같음)
