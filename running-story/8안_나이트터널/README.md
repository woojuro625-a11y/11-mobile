# 8안 나이트 터널 (노래 Split Card)

노래 'Split Card'를 제목과 상관없이 소리로 분석해서 만든 양식.
- 분석: 약 126BPM 어두운 하우스. 킥은 매 박(포 온 더 플로어), 오픈 하이햇은 박 사이(오프비트), E 프리지안(베이스가 E와 F를 반음으로 오가는 긴장감 있는 소리), 거의 모노. 구성은 조용한 인트로 → 베이스 한 방 → 하이햇이 차오르는 빌드업 → 드롭 → 베이스가 빠지는 브레이크 → 다시 드롭 → 마지막에 크게 한 번 치고(엔딩 히트) 울림이 사라짐
- 그래서: 밤의 터널을 달리는 영상. 검은 터널, 나트륨등 같은 호박색 조명, 청록 차선, 출구의 흰 빛. 곡이 달리는 속도를 정한다: 인트로는 천천히 → 빌드업에서 점점 빨라짐 → 드롭에서 최고 속도(빛 줄기) → 브레이크에서 늦춤 → 마지막 드롭 → 엔딩 히트 뒤 서서히 멈춤
- 움직임: 킥마다 터널 조명이 번쩍, 오프비트 하이햇마다 바닥 차선이 반짝. 장면 전환은 이전 화면이 카메라 쪽으로 커지며 지나가 사라짐(터널을 지나가듯). 엔딩 히트에 '완주' 출구 표지판이 초록으로 켜짐
- 스타 러너: 3D 모델이 카메라 쪽으로 달려옴 (진행 방향을 봄, 박마다 한 걸음, 터널 속도만큼 보폭), 곡이 끝나면 멈춰서 손을 흔듦
내용 규칙은 1안과 같다 (가민 캡처 원본, 실제 페이스, 한글 라벨, 쉼표·마침표 없음, 메모 줄바꿈 유지, 심박수 존 색, 1080×1920 60fps 30초).

## 음악
- `python3 -I scripts/music_edit.py 노래.wav music30.wav 임시.js 0 3.819 24.787 49.457 58.03 first`
  - 3.819~24.787초(인트로 3마디째부터 첫 드롭이 끝날 때까지 정확히 11마디) + 49.457초(마지막 드롭의 마지막 2마디)부터 곡의 끝까지 → 30초
  - 이음새가 마디 길이에 정확히 맞아 박자가 밀리지 않는다. 박자 격자 `beat.js`는 126.22BPM 고정 격자(0초가 첫 마디)로 직접 쓴다 (README 아래 코드)
- `python3 -I scripts/drums.py music30.wav beat.js drums.js` (킥 → 조명), `python3 -I scripts/bassenv.py music30.wav bass.js` (매 프레임 베이스·음량 → 출구 빛과 조명 세기)
- 효과음 `python3 scripts/sfx_b8.py beat.js sfx.wav`: 장면 전환마다 작은 바람 소리, 엔딩 히트에 표지판이 켜지는 전기 소리 / 피크 -18 dBFS

```python
b=60/126.22;import json
B=[[round(k*b,4),1 if k%4==0 else 0] for k in range(int(30/b)+1)]
open('beat.js','w').write('const BEATS='+json.dumps(B)+';\n')
```

## 구성 (편집본 마디 기준, 1마디 1.90초)
| 시간 | 곡 | 장면 | 내용 |
|---|---|---|---|
| 0~3.80초 | 인트로 | 오프닝 | 천천히 움직이는 터널, '오늘의 러닝' → 제목 → 메모·날짜, 사진 두 장이 호박색 빛 테두리 패널로 등장, 아래에서 달려오는 스타 러너 |
| 3.80~7.61초 | 베이스 한 방 | 가민 캡처 | 메모를 잘라낸 캡처 **전체 그대로**(확대·덧그림 없음), 왼쪽 호박색 꼬리표 '지도' '제목' '기록' |
| 7.61~11.41초 | 빌드업 | 구간 기록 | 1km부터 8km까지 위에서 아래로 박마다 한 줄씩(길수록 빠름), 가장 빠름 빨강·가장 느림 파랑, 평균페이스와 빠른·느린 1km 차이 |
| 11.41~17.11초 | 드롭 (최고 속도) | 페이스 그래프 | 청록 빛 선으로 실제 페이스, 최고 페이스가 나온 km를 빨갛게 비추고 3박 동안 천천히 그림 → '마지막 1km 스퍼트 / 순간 최고 4'01" / 8km 구간 4'58"' 카드가 장면 끝까지, 그 아래 평균·최고 페이스·총 거리, 구간 문구 |
| 17.11~20.92초 | 브레이크 → 그루브 | 심박존별 시간 | 가민 순서(5존→존 미만) 차선 조명처럼 칸칸이 켜지는 존 색 막대, 범위·시간·%, 평균·최대 심박수(존 색), 가장 오래 머문 존, 중간 멈춤 여부 |
| 20.92~30초 | 마지막 드롭 → 엔딩 히트(24.72초) → 울림 | 엔딩 | 제목, 꺼진 '완주' 표지판이 엔딩 히트에 초록으로 켜짐, 달려오는 스타 러너(울림이 시작되면 멈춰서 손 흔듦), 기록 6칸, 러닝 메모(줄바꿈 그대로, 스킬 `running-memo-emphasis`의 터널 스타일: 숫자 호박색 Saira Condensed + 연한 호박색 바탕, 몸 상태 빨강 차선 점선 밑줄, 다음 계획 청록 띠) |

## 새 기록으로 만들 때
1. `prep_run.py`, `breaks.py`로 data.js / 캡처는 `cut_memo.py`로 메모를 잘라 `img/garmin.png`, `CAP.h` 확인 / 사진 `img/photo1.jpg` `img/photo2.jpg`
2. `RUN`(제목·메모·후기·`reviewMarks`·사진 캡션) 수정
3. 노래가 같으면 `beat.js` `drums.js` `bass.js` 그대로
4. `python3 scripts/fonts_b8.py .` (먼저 `fonts/` 폴더) → `node scripts/render.js video 60 out.mp4` (3D라 WebGL 옵션 포함) → `sfx_b8.py`로 효과음 → `ffmpeg -i music30.wav -i sfx.wav -filter_complex "[0][1]amix=inputs=2:normalize=0,alimiter=limit=0.89" mix.wav` → 영상과 합치기
5. 확인: `../qc.sh out.mp4 qc폴더 980:540:50:1200 23 30`
