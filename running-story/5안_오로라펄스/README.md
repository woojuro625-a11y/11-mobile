# 5안 오로라 (노래 처음부터 그대로 + 차분한 진행)

노래 'Card Countdown'을 분석해서 제목과 상관없이 소리에 맞춘 컨셉.
- 분석: 약 129BPM, B♭ 장조(밝고 따뜻함), 화음·패드가 드럼보다 두 배 크고 스테레오가 넓음, 0~17.3초는 패드 중심으로 서서히 쌓이고 17.3초에 비트가 들어옴 → 멜로딕 하우스
- 그래서: 밤하늘 오로라와 반투명 유리 카드, 모든 움직임은 부드럽게 떠오르고 번지듯. **박자에 맞춰 튀거나 펌핑하는 연출은 넣지 않는다** (오로라는 천천히 흐르고, 곡이 쌓이는 만큼 17.3초까지 서서히 밝아질 뿐). 밤에 달린 기록과 사진의 분위기와도 맞음
- 박자 펌핑 심박 그래프는 3안만의 연출. 5안은 빛기둥이 한 번 천천히 차오르고 멈춘다
내용 규칙은 1안과 같다 (가민 캡처 원본, 실제 페이스, 한글 라벨, 쉼표·마침표 없음, 메모 줄바꿈 유지, 심박수 존 색, 마지막 약 10초 반복, 1080×1920 60fps 30초).

## 음악
- **편집 없이 곡의 처음부터 30초**, 26.5초부터 3.5초 동안 페이드아웃
  `ffmpeg -i 노래.wav -af "atrim=0:30,afade=t=out:st=26.5:d=3.5" music30.wav`
- 장면은 곡의 마디 첫 박에서 시작 (`beat.js`: 곡에서 찾은 박, 0.673초부터 네 박마다 마디 첫 박)
- 효과음 `scripts/sfx_b5.py beat.js sfx.wav`: 장면이 번질 때 아주 작은 바람 소리, '완주'에 곡 조성(B♭)에 맞춘 종소리 / 피크 -17 dBFS

## 구성
| 시간 | 장면 | 내용 |
|---|---|---|
| 0~4.39초 | 밤하늘 | 별과 오로라가 밝아지고 '오늘의 러닝', 사진 두 장이 유리 액자로 떠오름(손글씨 캡션), 제목·메모·날짜 |
| 4.39~8.09초 | 가민 캡처 | 메모를 잘라낸 캡처를 유리판 위에 **전체 그대로**, 왼쪽에 '지도' '제목' '기록' |
| 8.09~11.78초 | 구간 기록 | 1km부터 8km까지 위에서 아래로 빛 막대(길수록 빠름), 가장 빠름 분홍·가장 느림 파랑, 평균페이스와 빠른·느린 1km 차이 |
| 11.78~15.46초 | 페이스 그래프 | 청록→보라 빛 선으로 실제 페이스(약 9초 이동평균), 13.63초 마디에서 최고 페이스가 나온 km만 분홍으로 비추고 천천히 그림 → 유리 카드 '마지막 1km 스퍼트 / 순간 최고 4'01" / 8km 구간 4'58"'이 장면 끝까지 |
| 15.46~19.14초 | 심박존별 시간 | 존 색 빛기둥(존 미만 1존~5존)이 한 번 천천히 차오름, 범위·시간·%, 평균·최대 심박수(존 색), 가장 오래 머문 존, 중간 멈춤 여부 (17.3초에 곡의 비트가 들어오며 오로라가 가장 밝아짐) |
| 19.14~30초 | 엔딩 | 제목 + '완주'(종소리), 기록 6칸 유리 타일(총 거리 주황·달린시간 파랑·평균페이스 초록·심박수는 존 색), 유리 카드에 손글씨 러닝 메모(가민 줄바꿈 그대로), 밤하늘을 천천히 떠다니는 작은 우주인 스타 러너. 노래는 마지막 3.5초 동안 페이드아웃 |

## 새 기록으로 만들 때
1. `prep_run.py`, `breaks.py`로 data.js / 캡처는 `cut_memo.py`로 메모를 잘라 `img/garmin.png`, `CAP.h` 확인 / 사진 `img/photo1.jpg` `img/photo2.jpg`
2. `RUN`(제목·메모·후기·사진 캡션) 수정
3. 노래가 같으면 `beat.js` 그대로
4. `python3 scripts/fonts_b5.py .` → `node scripts/render.js video 60 out.mp4` → `python3 scripts/sfx_b5.py beat.js sfx.wav` → 노래와 섞어 합치기 (3안 README의 ffmpeg 명령과 같음)
5. 확인: `../qc.sh out.mp4 qc_dir` (0.2초마다 큰 시트 5장 + 엔딩 글자 영역 원본 크기 확대)
