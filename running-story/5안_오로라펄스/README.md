# 5안 오로라 펄스 (음악 편집 + 사이드체인 펌핑에 맞춘 진행)

노래 'Card Countdown'을 분석해서 제목과 상관없이 소리에 맞춘 컨셉.
- 분석 결과: 약 129BPM, B♭ 장조(밝고 따뜻함), 드롭에서 모든 박에 킥 + 킥마다 소리 전체가 눌렸다가 부풀어 오르는 **강한 사이드체인 펌핑**, 드럼보다 화음·패드가 두 배 큼, 스테레오가 넓음, 도입과 아웃트로는 패드 중심 → 멜로딕 하우스
- 그래서: 밤하늘 오로라가 노래의 펌핑처럼 킥마다 눌렸다 부풀고, 기록은 반투명 유리 카드 위에. 움직임은 부드럽게 떠오르고 번지듯 (4안의 하드 컷과 반대). 밤에 달린 기록과 사진의 분위기와도 맞음
내용 규칙은 1안과 같다 (가민 캡처 원본, 실제 페이스, 한글 라벨, 쉼표·마침표 없음, 메모 줄바꿈 유지, 심박수 존 색, 마지막 10초 반복, 1080×1920 60fps 30초).

## 음악
- `python3 -I scripts/music_edit.py 노래.wav music30.wav beat.js 0 13.63 33.89 48.599 58.72 first` (첫 드롭 두 마디 전부터 첫 드롭 끝까지 + 두 번째 드롭 끝 마디부터 곡 끝까지, 드롭 3.67초, 이음새 20.25초, 마지막 10초는 잔잔한 아웃트로)
- `python3 -I scripts/drums.py music30.wav beat.js drums.js` (킥 시각 → 펌핑)
- 효과음 `scripts/sfx_b5.py beat.js sfx.wav`: 장면이 번질 때 아주 작은 바람 소리, 드롭 직전 들숨, '완주'에 곡 조성(B♭)에 맞춘 종소리 / 피크 -17 dBFS

## 구성
| 시간 | 장면 | 내용 |
|---|---|---|
| 0~3.67초 (도입) | 밤하늘 | 별과 오로라가 서서히 밝아짐, '오늘의 러닝', 사진 두 장이 유리 액자로 떠오름(손글씨 캡션), 제목·메모·날짜 → 드롭 직전 한 마디 동안 화면이 숨을 들이쉬듯 밝아지고 드롭에 빛이 번짐 |
| 3.67~7.36초 (드롭) | 가민 캡처 | 메모를 잘라낸 캡처를 유리판 위에 **전체 그대로**, 왼쪽에 빛나는 '지도' '제목' '기록' |
| 7.36~11.05초 | 구간 기록 | 유리 판 위에 1km부터 8km까지 위에서 아래로 빛 막대(길수록 빠름, 킥마다 빛이 번짐), 가장 빠름 분홍·가장 느림 파랑, 평균페이스와 빠른·느린 1km 차이 |
| 11.05~14.75초 | 페이스 그래프 | 청록→보라 빛 선으로 실제 페이스(약 9초 이동평균)를 반 박자에 1km씩, 12.9초 마디에서 최고 페이스가 나온 km만 분홍 빛으로 비추고 두 박자에 걸쳐 그림 → 유리 카드 '마지막 1km 스퍼트 / 순간 최고 4'01" / 8km 구간 4'58"'이 장면 끝까지 |
| 14.75~18.44초 | 심박존별 시간 | 존 색 빛기둥(존 미만 1존~5존)이 **킥마다 0에서 그 존의 최대치까지 솟았다 가라앉음**(계속 켜진 최대치 표시 없음), 범위·시간·%, 평균·최대 심박수(존 색), 가장 오래 머문 존, 중간 멈춤 여부 |
| 18.44~20.25초 | 완주 | 오로라가 가장 밝아지고 '완주'가 떠오름, 종소리 |
| 20.25~30초 (아웃트로) | 엔딩 반복 | 제목 + '완주', 기록 6칸 유리 타일(총 거리 주황·달린시간 파랑·평균페이스 초록·심박수는 존 색), 유리 카드에 손글씨 러닝 메모(가민 줄바꿈 그대로), 밤하늘을 천천히 떠다니는 작은 우주인 스타 러너(가끔 손 흔듦) |

## 새 기록으로 만들 때
1. `prep_run.py`, `breaks.py`로 data.js / 캡처는 `cut_memo.py`로 메모를 잘라 `img/garmin.png`, `CAP.h` 확인 / 사진 `img/photo1.jpg` `img/photo2.jpg`
2. `RUN`(제목·메모·후기·사진 캡션) 수정
3. 노래가 같으면 `beat.js` `drums.js` 그대로. 바꾸면 `music_edit.py` → `drums.py`
4. `python3 scripts/fonts_b5.py .` → `node scripts/render.js video 60 out.mp4` → `python3 scripts/sfx_b5.py beat.js sfx.wav` → 노래와 섞어 합치기 (3안 README의 ffmpeg 명령과 같음)
