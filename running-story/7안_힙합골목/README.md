# 7안 힙합 골목 (노래 Echoes on the Offbeat)

노래 'Echoes on the Offbeat'(약 92BPM, G 단조, 원 드롭 킥, 박자 뒤 스캥크)를 쓰는 양식. 처음에는 덥 에코(잔상) 컨셉이었으나 잔상이 눈에 피로하다는 피드백으로 **잔상 효과를 모두 없애고** 힙합 골목으로 바꿨다.
- 테마: 실사 같은 밤의 뒷골목 사진(`img/alley.jpg`, Figma AI로 생성: 젖은 아스팔트에 비친 가로등과 마젠타 네온, 그라피티 벽, 비상계단, 맨홀 김). 화면이 아주 천천히 다가가고(푸시 인), 가로등 빛이 킥에 살짝 숨 쉬고, 김이 피어오르고, 필름 그레인. 데이터 장면은 흐리고 어둡게 한 사진(`img/alley_blur.jpg`, 심도 효과) 위에
- 글자: 장면 제목은 크림색 큰 글자 + 노란 밑줄, 위쪽은 어두운 그러데이션으로 글자가 잘 읽히게. 요소는 짧게 위로 올라오며 나타나고(잔상 없음), 장면 전환은 이전 화면이 왼쪽으로 밀려나며 사라짐
- 배경을 다른 장소로 바꾸려면: 세로 9:16 사진을 1188×2112로 만들어 `img/alley.jpg`에, 같은 사진을 흐리게(가우시안 14) 어둡게(0.62) 해서 `img/alley_blur.jpg`에
- 스타 러너: 3D 힙합 맨. 빨간 페이즐리 반다나 두건과 금목걸이(`hiphop3d.js`). 두건은 머리에 딱 맞는 모자가 아니라 천처럼 자연스럽게 씀: 살짝 기울어 쓰고, 이마 위로 접힌 검정 테두리 무늬 단이 물결치고, 뒤로 갈수록 주름이 모이고, 뒤에 접힌 삼각 끝·매듭·흔들리는 꼬리 두 가닥. 매 박마다 손을 위아래로 내리찍고 고개를 크게 끄덕이고 무릎으로 바운스. 마디마다 동작이 바뀜(두 손 펌프 / 번갈아 펌프 / 한 손 펌프 + 기대기 / 좌우 흔들기), 모든 관절이 부드러운 곡선으로 움직이고 마디가 바뀔 때 섞여 넘어감. 곡이 끝나면 멈춰서 손 흔듦
내용 규칙은 1안과 같다 (가민 캡처 원본, 실제 페이스, 한글 라벨, 쉼표·마침표 없음, 메모 줄바꿈 유지, 심박수 존 색, 1080×1920 60fps 30초).

## 음악
- `python3 -I scripts/music_full.py 노래.wav music30.wav beat.js first` — 곡의 처음부터 편집 없이 30초, 마지막 1초 페이드아웃
  - 박자 격자는 0.255초부터 1박 0.650초 고정 격자로 다시 씀(곡 끝까지 킥과 ±0.05초 안으로 맞음)
- `python3 -I scripts/drums.py music30.wav beat.js drums.js`, `python3 -I scripts/bassenv.py music30.wav bass.js`
- 효과음 `python3 scripts/sfx_b7h.py beat.js sfx.wav`: '완주' 도장에 스프레이 소리, 메모 카드에 카세트 버튼 딸깍 / 피크 -17 dBFS

## 타이포그래피
- 큰 제목(오늘의 러닝 제목·장면 제목·엔딩 제목·완주): **심플하게** 고딕 A1 Black 미색(#F3EEE4) 한 가지 색 + 은은한 그림자만 (`gtx()`). 흘러내림·두 톤 채우기·두꺼운 외곽선·번짐·기울기 없음. '오늘의 러닝'은 반투명 미색 작은 글자
- 숫자(페이스·시간·심박): Anton(좁고 굵은 힙합 포스터 숫자)
- 부제·메모·사진 캡션·작은 라벨: 도현체(Do Hyeon), 단위·작은 설명: Noto Sans KR
- **데이터 장면(구간 기록·페이스 그래프·심박존)은 골목 벽에 풀로 붙인 90년대 힙합 공연 전단지**(`poster()`): 누렇게 바랜 복사지, 토너 얼룩과 풀칠 주름, 접힌 자국, 찢어진 아래 가장자리, 모서리 테이프. 위에 검정 머리띠('SPLITS' 'PACE' 'HEART ZONES' + 작은 정보 줄 + 분홍 별)
  - 막대는 리소 인쇄 잉크(`inkBar()`): 망점, 시작 부분 잉크가 덜 묻은 느낌, 살짝 어긋나게 겹친 분홍 잉크. 기본 검정, 가장 빠름 형광 분홍, 가장 느림 파랑, 심박존은 존 색 잉크
  - 가장 빠른 기록은 빨간 마커 동그라미 + '가장 빠름' 손글씨, 가장 느림은 파란 도장
  - 페이스 그래프는 검정 잉크 선 + 아래 망점, 스퍼트 km는 분홍, 안내 카드는 검정 인쇄 블록
  - 원색 페인트 막대와 흘러내림은 쓰지 않는다(가볍고 특색 없어 보임)
- '완주'는 빨간 스프레이 원 + 흰·분홍 그래피티 글자
- 쓰지 않는 것: 손글씨 붓체, 영문 태그 낙서(지저분해 보임), Gasoek One(굵은 외곽선과 겹치면 '기록' '심박존별'이 잘 안 읽힘)

## 새 기록으로 만들 때
1. `prep_run.py`, `breaks.py`로 data.js / 캡처는 `cut_memo.py`로 메모를 잘라 `img/garmin.png`, `CAP.h` 확인 / 사진 `img/photo1.jpg` `img/photo2.jpg`
2. `RUN`(제목·메모·후기·`reviewMarks`·사진 캡션) 수정
3. 노래가 같으면 `beat.js` `drums.js` `bass.js` 그대로
4. `python3 scripts/fonts_b7.py .` (먼저 `fonts/` 폴더) → `node scripts/render.js video 60 out.mp4` (3D라 WebGL 옵션 포함) → `sfx_b7h.py`로 효과음 → `ffmpeg -i music30.wav -i sfx.wav -filter_complex "[0][1]amix=inputs=2:normalize=0,alimiter=limit=0.89" mix.wav` → 영상과 합치기
5. 확인: `../qc.sh out.mp4 qc폴더 960:450:60:1240 25 30`
