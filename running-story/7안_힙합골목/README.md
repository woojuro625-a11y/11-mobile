# 7안 힙합 골목 (노래 Echoes on the Offbeat)

노래 'Echoes on the Offbeat'(약 92BPM, G 단조, 원 드롭 킥, 박자 뒤 스캥크)를 쓰는 양식. 처음에는 덥 에코(잔상) 컨셉이었으나 잔상이 눈에 피로하다는 피드백으로 **잔상 효과를 모두 없애고** 힙합 골목으로 바꿨다.
- 테마: 밤의 뒷골목. 붉은 벽돌 벽, 은은한 스프레이 그라피티 얼룩과 흘러내린 자국(글자 없음), 위쪽 비상계단, 위에서 비추는 가로등, 땅에 놓인 붐박스(킥에 맞춰 스피커가 울리고 레벨 미터가 움직임)
- 글자: 장면 제목은 노란 스티커 라벨(살짝 기울어짐), 데이터 장면은 벽을 어둡게 눌러 숫자가 잘 읽히게. 요소는 짧게 위로 올라오며 나타나고(잔상 없음), 장면 전환은 이전 화면이 왼쪽으로 밀려나며 사라짐
- 스타 러너: 3D 힙합 맨. 빨간 페이즐리 두건(두랙, 뒤에 매듭과 꼬리)과 금목걸이(`hiphop3d.js`). 매 박마다 손을 위아래로 내리찍고 고개를 크게 끄덕이고 무릎으로 바운스. 마디마다 동작이 바뀜(두 손 펌프 / 번갈아 펌프 / 한 손 펌프 + 기대기 / 좌우 흔들기), 모든 관절이 부드러운 곡선으로 움직이고 마디가 바뀔 때 섞여 넘어감. 곡이 끝나면 멈춰서 손 흔듦
내용 규칙은 1안과 같다 (가민 캡처 원본, 실제 페이스, 한글 라벨, 쉼표·마침표 없음, 메모 줄바꿈 유지, 심박수 존 색, 1080×1920 60fps 30초).

## 음악
- `python3 -I scripts/music_edit.py 노래.wav music30.wav beat.js 0 0 20.96 49.83 58.2 first`
  - 곡의 처음부터 20.96초까지 + 49.83초부터 곡의 끝까지 → 30초. 이음새 21.0초가 엔딩 장면 시작
- `python3 -I scripts/drums.py music30.wav beat.js drums.js` (킥 → 붐박스), `python3 -I scripts/bassenv.py music30.wav bass.js` (매 프레임 음량 → 춤의 크기·레벨 미터)
- 효과음 `python3 scripts/sfx_b7h.py beat.js sfx.wav`: '완주' 도장에 스프레이 소리, 메모 카드에 카세트 버튼 딸깍 / 피크 -17 dBFS

## 구성 (1박 0.65초)
| 시간 | 장면 | 내용 |
|---|---|---|
| 0~5.46초 | 오프닝 | 골목, '오늘의 러닝' → 제목 → 메모·날짜, 사진 두 장이 테이프로 벽에 붙은 포스터처럼 등장, 아래에 붐박스와 춤추는 스타 러너 |
| 5.46~8.73초 | 가민 캡처 | 메모를 잘라낸 캡처 **전체 그대로**(확대·덧그림 없음), 왼쪽 노란 꼬리표 '지도' '제목' '기록' |
| 8.73~12.63초 | 구간 기록 | 1km부터 8km까지 위에서 아래로(길수록 빠름), 가장 빠름 빨강·가장 느림 파랑, 평균페이스와 빠른·느린 1km 차이 |
| 12.63~17.86초 | 페이스 그래프 | 실제 페이스 선, 최고 페이스가 나온 km를 빨갛게 비추고 천천히 그림 → '마지막 1km 스퍼트 / 순간 최고 4'01" / 8km 구간 4'58"' 카드가 장면 끝까지 |
| 17.86~20.99초 | 심박존별 시간 | 가민 순서(5존→존 미만) 존 색 막대, 범위·시간·%, 평균·최대 심박수(존 색), 가장 오래 머문 존, 중간 멈춤 여부 |
| 20.99~30초 | 엔딩 | 제목 + 노란 '완주' 도장, 붐박스와 손을 내리찍는 스타 러너, 어두운 판 위의 기록 6칸, 러닝 메모(줄바꿈 그대로, 스킬 `running-memo-emphasis`: 숫자 노랑 Alfa Slab One + 연한 노랑 바탕, 몸 상태 빨강 마커 밑줄, 다음 계획 초록 띠) |

## 새 기록으로 만들 때
1. `prep_run.py`, `breaks.py`로 data.js / 캡처는 `cut_memo.py`로 메모를 잘라 `img/garmin.png`, `CAP.h` 확인 / 사진 `img/photo1.jpg` `img/photo2.jpg`
2. `RUN`(제목·메모·후기·`reviewMarks`·사진 캡션) 수정
3. 노래가 같으면 `beat.js` `drums.js` `bass.js` 그대로
4. `python3 scripts/fonts_b7.py .` (먼저 `fonts/` 폴더) → `node scripts/render.js video 60 out.mp4` (3D라 WebGL 옵션 포함) → `sfx_b7h.py`로 효과음 → `ffmpeg -i music30.wav -i sfx.wav -filter_complex "[0][1]amix=inputs=2:normalize=0,alimiter=limit=0.89" mix.wav` → 영상과 합치기
5. 확인: `../qc.sh out.mp4 qc폴더 960:450:60:1240 25 30`
