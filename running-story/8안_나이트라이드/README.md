# 8안 나이트 라이드 (노래 Split Card)

노래 'Split Card'를 제목과 상관없이 소리로 분석해서 만든 양식.
- 분석: 약 126BPM 어두운 하우스. 킥은 매 박(포 온 더 플로어), 오픈 하이햇은 박 사이(오프비트), E 프리지안(베이스가 E와 F를 반음으로 오가는 긴장감 있는 소리), 거의 모노. 구성은 조용한 인트로 → 베이스 한 방 → 하이햇이 차오르는 빌드업 → 드롭 → 베이스가 빠지는 브레이크 → 다시 드롭 → 마지막에 크게 한 번 치고(엔딩 히트) 울림이 사라짐
- 그래서: 밤의 고속도로를 오토바이로 달리는 카메라 뷰. 배경은 실사 같은 사진 두 장(Figma AI로 생성): `img/hwy_open.jpg`(텅 빈 밤 고속도로, 도시 불빛, 나트륨 가로등, 젖은 노면)과 `img/hwy_pov.jpg`(핸들 너머 운전자 시점). 운전자 시점 사진에서 핸들·계기판·연료탱크만 오려 낸 `img/cockpit.png`를 앞에 고정하고, 도로 사진은 소실점을 중심으로 끝없이 확대되며(두 장을 겹쳐 이어 붙임) 속도감을 낸다
- 속도 효과: 곡이 달리는 속도를 정한다(인트로 천천히 → 빌드업에서 점점 빨라짐 → 드롭에서 최고 속도 → 브레이크에서 늦춤 → 마지막 드롭 → 엔딩 히트 뒤 서서히 멈춤). 속도가 빠를수록 확대 블러(줌 블러)와 빛 줄기가 많아지고, 킥마다 가로등이 번쩍, 핸들이 노면과 킥에 맞춰 살짝 떨림. 장면 전환은 이전 화면이 카메라 쪽으로 커지며 지나감
- **데이터를 계기판·내비게이션에**: 가민 캡처는 핸들 거치대의 휴대폰 화면에(전체 그대로), 구간 기록은 계기판 LAP 화면의 LED 막대, 페이스 그래프는 내비게이션 화면의 경로(위치 화살표가 경로를 따라 달림, 스퍼트 구간은 빨간 경로 + 카드), 심박존은 LED 막대 + 회전계 같은 심박 게이지(바늘이 평균심박수, 빨간 표시가 최대심박수)
- 스타 러너: 오프닝과 엔딩의 주인공. 바이크 고글을 쓰고 오토바이(검은 차체, 청록 탱크)를 운전함(`rider3d.js`). 곡에 따라 동작이 계속 바뀜: 도로가 휘는 대로 몸을 기울이고, 박마다 고개를 끄덕이고, 오프닝에서 카메라 쪽을 봤다가 앞을 보고, 마지막 드롭에서 몸을 숙여 속도를 내고, 주먹을 한 번 들고, 엔딩 히트에 윌리(앞바퀴 들기), 울림이 시작되면 멈춰 앉아 손을 흔듦
- 데이터 장면에서는 이스터에그: 계기판 위에 작은 스타 러너 버블헤드 인형이 서서 노면과 박자에 맞춰 고개를 끄덕임. 엔딩 히트의 화면 번쩍임은 아주 약하게
내용 규칙은 1안과 같다 (가민 캡처 원본, 실제 페이스, 한글 라벨, 쉼표·마침표 없음, 메모 줄바꿈 유지, 심박수 존 색, 1080×1920 60fps 30초).

## 음악
- `python3 -I scripts/music_full.py 노래.wav music30.wav beat.js first 126.22 0.056` — 곡의 처음부터 편집 없이 30초, 마지막 1초 페이드아웃 (126.22BPM 고정 격자)
  - 첫 30초 구조: 0~5.8초 인트로 → 5.8초 베이스 → 9.6~15.3초 빌드업 → 15.3초 드롭 → 21.0초 브레이크 → 22.9초 다시 드롭(엔딩 장면의 히트) → 29~30초 페이드아웃
- `python3 -I scripts/drums.py music30.wav beat.js drums.js`, `python3 -I scripts/bassenv.py music30.wav bass.js`
- 효과음 `python3 scripts/sfx_b8m.py beat.js sfx.wav`: 장면 전환 바람 소리, 다시 들어오는 드롭에 윌리 엔진 소리와 '완주' 표지판 전기 소리 / 피크 -18 dBFS

## 화면
- 오토바이 핸들·계기판을 오려 붙인 운전자 시점은 쓰지 않는다(배경과 경계가 생겨 어색함). **도로 사진이 화면 전체(아래까지)를 채우고** 소실점을 향해 끝없이 확대되며 달린다
- 스타 러너 이스터에그: 데이터 장면마다 한 번씩 오토바이를 탄 스타 러너가 카메라를 추월해 지평선 쪽으로 멀어짐(뒷모습, 빨간 미등). 화면 아래에서 작게 나타나 서서히 사라짐

## 구성 (편집본 마디 기준, 1마디 1.90초)
| 시간 | 곡 | 장면 | 내용 |
|---|---|---|---|
| 0~3.80초 | 인트로 | 오프닝 | 밤의 고속도로(카메라가 스타 러너 앞에서 뒤로 달림), '오늘의 러닝' → 제목 → 메모·날짜, 사진 두 장이 호박색 빛 테두리 패널로 등장, 아래에서 고글 쓰고 오토바이를 모는 스타 러너 |
| 3.80~7.61초 | 베이스 한 방 | 가민 캡처 | 운전자 시점. 핸들 거치대의 휴대폰에 메모를 잘라낸 캡처 **전체 그대로**(확대·덧그림 없음), 왼쪽 호박색 꼬리표 '지도' '제목' '기록' |
| 7.61~11.41초 | 빌드업 | 구간 기록 | 1km부터 8km까지 위에서 아래로 박마다 한 줄씩(길수록 빠름), 가장 빠름 빨강·가장 느림 파랑, 평균페이스와 빠른·느린 1km 차이 |
| 11.41~17.11초 | 드롭 (최고 속도) | 페이스 그래프 | 청록 빛 선으로 실제 페이스, 최고 페이스가 나온 km를 빨갛게 비추고 천천히 그림 → 스퍼트 카드가 장면 끝까지, 그 아래 평균·최고 페이스·총 거리, 구간 문구 |
| 17.11~20.92초 | 브레이크 → 그루브 | 심박존별 시간 | 가민 순서(5존→존 미만) 차선 조명처럼 칸칸이 켜지는 존 색 막대, 범위·시간·%, 평균·최대 심박수(존 색), 가장 오래 머문 존, 중간 멈춤 여부 |
| 20.92~30초 | 마지막 드롭 → 엔딩 히트(24.72초) → 울림 | 엔딩 | 제목, '완주' 출구 표지판, 오토바이 탄 스타 러너(숙임 → 주먹 → 윌리 → 멈춤 → 손 흔듦), 기록 6칸, 러닝 메모(줄바꿈 그대로, 스킬 `running-memo-emphasis`: 숫자 호박색 Saira Condensed + 연한 호박색 바탕, 몸 상태 빨강 차선 점선 밑줄, 다음 계획 청록 띠) |

## 새 기록으로 만들 때
1. `prep_run.py`, `breaks.py`로 data.js / 캡처는 `cut_memo.py`로 메모를 잘라 `img/garmin.png`, `CAP.h` 확인 / 사진 `img/photo1.jpg` `img/photo2.jpg`
2. `RUN`(제목·메모·후기·`reviewMarks`·사진 캡션) 수정
3. 노래가 같으면 `beat.js` `drums.js` `bass.js` 그대로
4. `python3 scripts/fonts_b8.py .` (먼저 `fonts/` 폴더) → `node scripts/render.js video 60 out.mp4` (3D라 WebGL 옵션 포함) → `sfx_b8m.py`로 효과음 → `ffmpeg -i music30.wav -i sfx.wav -filter_complex "[0][1]amix=inputs=2:normalize=0,alimiter=limit=0.89" mix.wav` → 영상과 합치기
5. 확인: `../qc.sh out.mp4 qc폴더 980:540:50:1200 23 30`
