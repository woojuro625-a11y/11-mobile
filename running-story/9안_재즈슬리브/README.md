# 9안 재즈 슬리브 (노래 Shoes Back in the Box)

노래를 제목과 상관없이 소리로 분석해서 만든 양식.
- 분석: 약 84.7BPM의 여유 있는 그루브, G장조에 F 화음이 섞인 블루지하고 따뜻한 화성(G → Em → F → C, 한 마디에 한 화음). 피아노·기타 화음을 박마다 짧게 끊어 치는 스타카토, 음정이 미끄러지는 슬라이드 베이스, 좌우로 넓은 스테레오(지금까지 노래 중 가장 넓음), 보컬 없이 악기 위주. 마디는 화음이 바뀌는 2.59초에서 시작(1마디 2.83초), 16초쯤부터 베이스와 드럼이 진해짐
- 그래서: 모던 재즈 레코드 슬리브. 미색 종이(#EDE6D6), 먹색(#141414), 코발트 블루(#2347C6), 탠저린(#FF6A1F)의 평면 색면, 두 톤 사진, 좁고 굵은 숫자. 6안(밝은 레트로 TV쇼)·7안(힙합 골목)과 겹치지 않게 정제된 그래픽 디자인 쪽
- 움직임: 끊어 치는 화음처럼 모든 요소가 부드럽게 미끄러지지 않고 0.12초 동안 세 번 툭툭 끊기며 제자리에 들어옴(`snap()` 스톱모션). 장면은 마디 첫 박에 색면(코발트·탠저린·먹색)이 화면을 계단식으로 가로지르며 바뀜
- 글꼴: 숫자 Big Shoulders Display(700·800·900), 제목·라벨 IBM Plex Sans KR(500·700), 메모 고운바탕(재킷 뒷면 해설지 느낌)
- 스타 러너: 검정 펠트 베레모를 오른쪽으로 비스듬히 쓴 재즈맨(`jazz3d.js`, 별 안테나가 베레모 위로 나옴). 기본 자세는 팔을 편하게 내림. 마디마다 어깨 흔들기 → 2·4박 손가락 스냅(손을 번갈아) → 사이드 스텝 → 셔플이 섞여 넘어감. 오프닝과 엔딩의 주인공이고, 마지막 페이드아웃에 멈춰서 손을 흔듦. **데이터 장면에서는 이스터에그**: 워킹 베이스에 맞춰 화면 맨 아래를 작게 걸어서 지나감(걷는 방향을 봄)
내용 규칙은 1안과 같다 (가민 캡처 원본, 실제 페이스, 한글 라벨, 쉼표·마침표 없음, 메모 줄바꿈 유지, 심박수 존 색, 1080×1920 60fps 30초, 22초부터 엔딩 전체 유지).

## 음악
- `python3 -I scripts/music_full.py 노래.wav music30.wav 임시.js first 84.69 2.593` — 곡의 처음부터 편집 없이 30초, 마지막 1초 페이드아웃
- 박자 격자 `beat.js`는 84.69BPM 고정 격자(첫 마디 2.593초, 그 앞 0.47·1.18·1.88초는 못갖춘마디)로 직접 쓴다:
```python
import json;b=60/84.69;d0=2.593-4*b
B=[[round(d0+k*b,4),k%4==0] for k in range(60) if 0<=d0+k*b<30]
open('beat.js','w').write('const BEATS='+json.dumps(B)+';')
```
- `python3 -I scripts/drums.py music30.wav beat.js drums.js`, `python3 -I scripts/bassenv.py music30.wav bass.js`
- 효과음 `python3 scripts/sfx_b9.py beat.js sfx.wav`: 장면이 바뀔 때 종이 재킷이 미끄러지는 소리, '완주' 스티커 팝 / 피크 -18 dBFS

## 구성 (마디 기준, 1마디 2.83초)
| 시간 | 장면 | 내용 |
|---|---|---|
| 0~5.43초 | 재킷 앞면 | 먹색 바탕, 사진 세 장이 박마다 한 장씩 두 톤 띠로 올라옴(코발트·탠저린·따뜻한 회색, `scripts/duotone.py`로 미리 만든 `img/duo1~3.png`)과 캡션, 제목, 탠저린 띠의 메모, 날짜와 코발트 선, 큰 거리 숫자, 오른쪽 아래 베레모 스타 러너 |
| 5.43~8.26초 | 가민 캡처 | 미색 바탕, 코발트 색면 위에 메모를 잘라낸 캡처 **전체 그대로**(확대·덧그림 없음), 왼쪽 흰 꼬리표 '지도' '제목' '기록' |
| 8.26~12.51초 | 구간 기록 | 레코드 뒷면 곡 목록처럼: 큰 숫자+작은 km, 코발트 평면 막대(길수록 빠름), 오른쪽 기록 열, 줄 사이 가는 선. 가장 빠름 탠저린, 가장 느림 먹선 테두리. 아래 평균페이스(크게)와 빠른·느린 구간 차이 |
| 12.51~16.76초 | 페이스 그래프 | 먹선 아래 코발트 면, 가장 빠른 순간이 나온 km를 탠저린으로 비추고 천천히 그림, 선 위 사각 표시 → 검정 카드(탠저린 세로 띠, 순간 최고·그 km 구간)가 장면 끝까지, 아래 평균·최고 페이스·총 거리와 구간 문구 |
| 16.76~19.60초 | 심박존별 시간 | 가민 순서(5존→존 미만) 존 색 평면 막대, 범위·시간·%, 평균·최대 심박수 크게(존 색), 가장 오래 머문 존, 중간 멈춤 여부 |
| 19.60~30초 | 재킷 뒷면 | 위 코발트 띠에 제목과 탠저린 '완주' 스티커, 가운데 베레모 스타 러너, 기록 6칸(좁고 굵은 숫자), 미색 해설지 카드의 러닝 메모(줄바꿈 그대로, 스킬 `running-memo-emphasis`: 숫자 탠저린 Big Shoulders + 연한 탠저린 바탕, 몸 상태 빨강 밑줄, 다음 계획 코발트 띠, 감정 코발트 두 줄 밑줄, 핵심 굵게 + 먹 밑줄). 21.9초까지 모두 나오고 끝까지 유지 |

## 새 기록으로 만들 때
1. `prep_run.py`, `breaks.py`로 data.js / 캡처는 `cut_memo.py`로 메모를 잘라 `img/garmin.png`, `CAP.h` 확인
2. 사진 `img/photo1~3.jpg` → 두 톤 띠 만들기: `python3 -I scripts/duotone.py img/photo1.jpg img/duo1.png '#141414' '#2347C6' '#9DB4FF'`, `photo2 → duo2 '#141414' '#FF6A1F' '#FFD3B0'`, `photo3 → duo3 '#1A1A1A' '#8C877C' '#F6F1E6'` (파일로 열면 브라우저가 픽셀을 못 읽어서 미리 만든다)
3. `RUN`(제목·메모·후기·`reviewMarks`·사진 캡션) 수정
4. 노래가 같으면 `beat.js` `drums.js` `bass.js` 그대로
5. `python3 scripts/fonts_b9.py .` (먼저 `fonts/` 폴더) → `node scripts/render.js video 60 out.mp4` (3D라 WebGL 옵션 포함) → `sfx_b9.py`로 효과음 → `ffmpeg -i music30.wav -i sfx.wav -filter_complex "[0][1]amix=inputs=2:normalize=0,alimiter=limit=0.89" mix.wav` → 영상과 합치기
6. 확인: `../qc.sh out.mp4 qc폴더 960:520:60:1250 21 30`
