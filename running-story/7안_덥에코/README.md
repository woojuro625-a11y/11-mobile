# 7안 덥 에코 (노래 Echoes on the Offbeat)

노래 'Echoes on the Offbeat'를 분석해서 만든 양식.
- 분석: 약 92BPM 덥 레게, G 단조, 거의 모노. 기타 스캥크가 박자 뒤('앤')에 끊어 치고, 킥은 3박에 떨어지는 원 드롭, 8분음표(0.325초) 간격의 테이프 에코가 소리마다 따라붙음
- 그래서: 밤의 사운드 시스템. 짙은 초록빛 검정 벽, 크림색 글자, 호박색·잎 초록·빨강 포인트, 나무 스피커. 화면에 나오는 것마다 곡의 에코 시간만큼 뒤에 흐려지는 잔상이 2~3번 따라옴(테이프 에코)
- 움직임: 스피커 콘이 원 드롭 킥에 맞춰 울리고, 화면 아래 'ECHO' 램프 4개가 박마다 에코처럼 차례로 켜졌다 꺼짐. 사진은 박자 뒤('앤')에 붙음. 장면 전환은 이전 화면이 오른쪽으로 잔상을 남기며 사라짐
- 스타 러너: 3D 모델이 스캥크 댄스(박자 뒤에 무릎을 굽히고 팔을 천천히 흔들고 고개를 끄덕임)
내용 규칙은 1안과 같다 (가민 캡처 원본, 실제 페이스, 한글 라벨, 쉼표·마침표 없음, 메모 줄바꿈 유지, 심박수 존 색, 1080×1920 60fps 30초).

## 음악
- `python3 -I scripts/music_edit.py 노래.wav music30.wav beat.js 0 0 20.96 49.83 58.2 first`
  - 곡의 처음부터 20.96초까지 + 49.83초부터 곡의 끝(에코가 사라지는 엔딩)까지 → 30초. 이음새 21.0초가 엔딩 장면 시작
- `python3 -I scripts/drums.py music30.wav beat.js drums.js` (원 드롭 킥 → 스피커), `python3 -I scripts/bassenv.py music30.wav bass.js` (매 프레임 베이스·음량 → 빛과 춤의 크기)
- 효과음 `python3 scripts/sfx_b7.py beat.js sfx.wav`: '완주' 도장에 림샷, 메모 카드에 테이프 딸깍. 둘 다 곡과 같은 8분음표 에코가 붙음 / 피크 -17 dBFS

## 구성 (박 기준, 1박 0.65초)
| 시간 | 장면 | 내용 |
|---|---|---|
| 0~5.46초 | 오프닝 | 나무 스피커 두 대, '오늘의 러닝' → 제목 → 메모·날짜가 잔상과 함께 등장, 사진 두 장이 박자 뒤에 포스터처럼 붙음, 아래에서 스캥크 추는 스타 러너 |
| 5.46~8.73초 | 가민 캡처 | 메모를 잘라낸 캡처 **전체 그대로**(확대·덧그림 없음), 왼쪽 호박색 꼬리표 '지도' '제목' '기록' |
| 8.73~12.63초 | 구간 기록 | 1km부터 8km까지 위에서 아래로 반 박마다 막대가 잔상과 함께 들어옴(길수록 빠름), 가장 빠름 빨강·가장 느림 파랑, 평균페이스와 빠른·느린 1km 차이 |
| 12.63~17.86초 | 페이스 그래프 | 실제 페이스 선이 그려지고 그 뒤를 호박색 에코 선 3개가 따라옴, 최고 페이스가 나온 km를 빨갛게 비추고 천천히 그림 → '마지막 1km 스퍼트 / 순간 최고 4'01" / 8km 구간 4'58"' 카드가 장면 끝까지 |
| 17.86~20.99초 | 심박존별 시간 | 가민 순서(5존→존 미만) 존 색 막대(펌핑 없음), 범위·시간·%, 평균·최대 심박수(존 색), 가장 오래 머문 존, 중간 멈춤 여부 |
| 20.99~30초 | 엔딩 | 스피커 + 제목 + 빨간 '완주' 도장, 가운데 스캥크 추는 스타 러너, 기록 6칸, 러닝 메모(줄바꿈 그대로, 스킬 `running-memo-emphasis`의 덥 스타일: 숫자 호박색 Alfa Slab One + 연한 호박색 바탕, 몸 상태 빨강 밑줄과 그 밑줄의 에코 2줄, 다음 계획 초록 띠, 줄마다 잔상이 남았다 사라짐) |

## 새 기록으로 만들 때
1. `prep_run.py`, `breaks.py`로 data.js / 캡처는 `cut_memo.py`로 메모를 잘라 `img/garmin.png`, `CAP.h` 확인 / 사진 `img/photo1.jpg` `img/photo2.jpg`
2. `RUN`(제목·메모·후기·`reviewMarks`·사진 캡션) 수정
3. 노래가 같으면 `beat.js` `drums.js` `bass.js` 그대로
4. `python3 scripts/fonts_b7.py .` (먼저 `fonts/` 폴더) → `node scripts/render.js video 60 out.mp4` (3D라 WebGL 옵션 포함) → `sfx_b7.py`로 효과음 → `ffmpeg -i music30.wav -i sfx.wav -filter_complex "[0][1]amix=inputs=2:normalize=0,alimiter=limit=0.89" mix.wav` → 영상과 합치기
5. 확인: `../qc.sh out.mp4 qc폴더 960:450:60:1240 25 30`
