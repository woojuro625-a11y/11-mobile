# 6안 펑크 TV 쇼 (음악 편집 + 그루브)

노래 'Pocket Funk'를 분석해서 만든 양식.
- 분석: 약 96BPM, C 장조, 베이스와 저음역이 소리의 76%로 따뜻하고 묵직함, 거의 모노에 가까운 빈티지한 소리, 스윙이 들어간 16분음표 그루브(펑크의 '포켓'), 킥은 1·3박 스네어는 2·4박, 시작부에 펑크 특유의 끊었다 치는 스탑, 곡 끝에 진짜 엔딩(마지막 화음이 울리다 사라짐)
- 그래서: 70년대 펑크 TV 쇼. 크림색 종이, 은은하게 번지는 따뜻한 빛(햇살 무늬·회전하는 선버스트는 쓰지 않음: 욱일기처럼 보일 수 있어 제거), 주황·머스터드·갈색 줄무늬, 둥근 레트로 글자(Jua, Shrikhand), 나무 TV. 3안 LP바의 어두운 밤 분위기와 달리 밝은 낮의 레트로
- 움직임: 요소들이 '보잉' 하고 튀어나오고 2·4박 스네어(백비트)에 맞춰 살짝 들썩임. 화면 아래 굵은 줄무늬 선이 곡의 실제 베이스 세기만큼 떨림(베이스 라인). 장면 전환은 70년대 세 줄 줄무늬 와이프
- 스타 러너: 3D 모델로 매 프레임 춤추는 펑크 댄서 (`dancer3d.js`, 마디마다 그루브·디스코 포인트·사이드 스텝·트위스트·시미가 돌아가며, 모든 관절이 부드러운 곡선으로 움직이고 마디가 바뀔 때 이전 동작에서 다음 동작으로 섞여 넘어감(뚝뚝 끊김 없음), 곡의 마지막 화음에 '짜잔' 포즈 후 소리가 잦아드는 만큼 천천히 멈춤). 헬멧이 커서 팔을 머리 위로 들면 가려지므로 팔은 옆·앞으로, 춤은 몸(바운스·트위스트·어깨·다리)으로
내용 규칙은 1안과 같다 (가민 캡처 원본, 실제 페이스, 한글 라벨, 쉼표·마침표 없음, 메모 줄바꿈 유지, 심박수 존 색, 마지막 10초 엔딩, 1080×1920 60fps 30초).

## 음악
- `python3 -I scripts/music_edit.py 노래.wav music30.wav beat.js 0 0 19.68 183.88 194.0 kick`
  - 곡의 처음부터 6마디 끝(19.68초)까지 + 곡의 마지막 섹션(183.88초)부터 진짜 엔딩까지 → 30초. 이음새 19.67초가 엔딩 장면 시작
  - 편집본 24.7초에 마지막 화음, 29.3초쯤 소리가 사라짐 (페이드아웃 없이 곡 자체의 엔딩)
- `python3 -I scripts/drums.py music30.wav beat.js drums.js` (스네어 백비트 → 들썩임), `python3 -I scripts/bassenv.py music30.wav bass.js` (매 프레임 베이스 세기 → 베이스 라인과 춤의 크기)
- 효과음 `scripts/sfx_b6.py beat.js sfx.wav`: TV 켜지는 소리, '완주' 스티커 팝, 메모 카드 팝뿐 / 피크 -17 dBFS

## 구성 (마디·반 마디 기준)
| 시간 | 장면 | 내용 |
|---|---|---|
| 0~4.53초 | 오프닝 | 곡의 스탑에 맞춰 '오늘의 러닝' → 제목(70년대 겹그림자 글자) → 메모 알약 → 날짜, 오늘의 사진 두 장이 둥근 레트로 TV 프레임으로 튀어나오고 백비트에 들썩임, 아래에서 춤추는 스타 러너 |
| 4.53~8.29초 | 가민 캡처 | 메모를 잘라낸 캡처를 70년대 TV 화면에 **전체 그대로**(확대·덧그림 없음). TV는 나뭇결 캐비닛과 입체감, 크롬 화면 테두리, 금속 패널의 채널 다이얼·볼륨 노브, 천 스피커 그릴, 황동 배지, 토끼 귀 안테나, 다리와 바닥 그림자. 왼쪽 머스터드 알약 라벨 '지도' '제목' '기록' |
| 8.29~12.05초 | 구간 기록 | 1km부터 8km까지 위에서 아래로 70년대 세 줄 줄무늬 알약 막대(길수록 빠름), 가장 빠름 빨강·가장 느림 청록 스티커, 평균페이스와 빠른·느린 1km 차이 |
| 12.05~15.81초 | 페이스 그래프 | 갈색 테두리와 그림자가 있는 70년대 차트 카드, 숫자는 Oswald(축·km별 페이스 알약), 갈색·주황·머스터드 세 줄 페이스 선 + 머스터드 그러데이션 채움, 최고 페이스가 나온 km를 은은한 주황 기둥으로 비추고 빨간 선으로 천천히 그림 → 머스터드 배지 '마지막 1km 스퍼트 / 순간 최고 4'01" / 8km 구간 4'58"'이 장면 끝까지 |
| 15.81~19.67초 | 심박존별 시간 | 가민 순서(5존→존 미만) 존 색 둥근 막대, 범위·시간·%, 평균·최대 심박수(존 색), 가장 오래 머문 존, 중간 멈춤 여부 |
| 19.67~30초 | 엔딩 | 제목 + 빨간 '완주' 둥근 스티커, 가운데 춤추는 스타 러너(마지막 화음에 짜잔 포즈), 기록 6칸 레트로 타일(총 거리 주황·달린시간 파랑·평균페이스 초록·심박수는 존 색), 러닝 메모 카드(줄바꿈 그대로, 스킬 `running-memo-emphasis`의 70년대 스타일: 숫자 주황 Shrikhand + 주황 동그라미, 몸 상태 빨강 물결 밑줄, 다음 계획 머스터드 형광펜) |

## 새 기록으로 만들 때
1. `prep_run.py`, `breaks.py`로 data.js / 캡처는 `cut_memo.py`로 메모를 잘라 `img/garmin.png`, `CAP.h` 확인 / 사진 `img/photo1.jpg` `img/photo2.jpg`
2. `RUN`(제목·메모·후기·`reviewMarks`·사진 캡션) 수정
3. 노래가 같으면 `beat.js` `drums.js` `bass.js` 그대로
4. `python3 scripts/fonts_b6.py .` → `node scripts/render.js video 60 out.mp4` (3D라 WebGL 옵션 포함) → 효과음 만들고 노래와 섞어 합치기 (3안 README의 ffmpeg 명령과 같음)
5. 확인: `../qc.sh out.mp4 qc폴더 1000:520:40:1240 19.5 30`
