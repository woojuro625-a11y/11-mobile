# 5안 카드 테이블 (음악 편집 + 박자 진행)

노래 'Card Countdown'(약 129BPM, 낮고 묵직한 베이스, 모든 박에 킥이 들어가는 4박 킥)에 맞춘 양식.
제목 그대로 **카드와 카운트다운**: 초록 펠트 테이블, 위에서 떨어지는 조명, 박자에 맞춰 딜러가 카드를 나눠 주고, 드롭 직전과 엔딩 직전에 카드 세 장이 3 2 1로 뒤집힌다.
내용 규칙은 1안과 같다 (가민 캡처 원본, 실제 페이스, 한글 라벨, 쉼표·마침표 없음, 메모 줄바꿈 유지, 심박수 존 색, 마지막 10초 반복, 1080×1920 60fps 30초).

## 음악 (Card Countdown)
- 곡 구조: 0~17.3초 서서히 쌓이는 도입 → 17.3초 드롭(4박 킥) → 33.9초 한 마디 쉼 → 35.7초 두 번째 드롭 → 50.4초부터 잔잔한 아웃트로
- `python3 -I scripts/music_edit.py 노래.wav music30.wav beat.js 0 13.63 33.89 48.599 58.72 first`
  - 첫 드롭 두 마디 전(13.63초)부터 첫 드롭 끝(33.89초)까지 + 두 번째 드롭이 끝나는 마디(48.6초)부터 곡 끝까지
  - 편집본에서 드롭은 3.67초, 이음새는 20.25초 → 마지막 10초 반복이 잔잔한 아웃트로 위에 놓인다
  - 모든 박에 킥이 있어 마디 첫 박은 `first`(편집본 첫 박이 마디 첫 박)
- `python3 -I scripts/drums.py music30.wav beat.js drums.js` (킥 세기: 조명이 킥마다 살짝 밝아지고 칩이 튐)
- 효과음 `scripts/sfx_b5.py beat.js sfx.wav`: 카드 나눠 주는 소리, 뒤집는 소리, 칩 쌓는 소리 / 피크 -15 dBFS로 노래 밑에 작게

## 구성
| 시간 | 장면 | 내용 |
|---|---|---|
| 0~3.67초 (도입 두 마디) | 카운트다운 | 조명이 켜지고 '오늘의 러닝', 오늘의 사진 두 장이 카드로 나눠짐(손글씨 캡션), 제목·메모·날짜 → 드롭 전 세 박에 카드 3 2 1 |
| 3.67~7.36초 (드롭) | 가민 캡처 | 캡처 비율이 트럼프 카드와 거의 같아서 **캡처가 큰 카드 한 장의 앞면**, 드롭에 뒤집힘(전체 그대로, 확대·덧그림 없음). 왼쪽에 금색 딜러 버튼 '지도' '제목' '기록' |
| 7.36~11.05초 | 구간 기록 | 1km부터 8km까지 가로 카드가 반 박자마다 위에서 아래로 나눠짐(숫자 + 무늬, 금빛 막대가 길수록 빠름), 가장 빠름 빨강 하트·가장 느림 파랑 스페이드, 평균페이스와 빠른·느린 1km 차이 |
| 11.05~14.75초 | 페이스 그래프 | 펠트 위 금색 실제 페이스(약 9초 이동평균)를 반 박자에 1km씩, 12.9초 마디에서 최고 페이스가 나온 km만 빨갛게 비추고 두 박자에 걸쳐 그림 → 'A♥' 카드 '마지막 1km 스퍼트 / 순간 최고 4'01" / 8km 구간 4'58"'이 장면 끝까지 |
| 14.75~18.44초 | 심박존별 시간 | 존 색 포커 칩 탑(존 미만 1존~5존, 칩 높이 = 머문 시간), 16분음표마다 칩이 쌓이고 킥마다 맨 위 칩이 튐, 범위·시간·%, 평균·최대 심박수(존 색), 가장 오래 머문 존, 중간 멈춤 여부 |
| 18.44~20.25초 | FINAL HAND | 엔딩 전 마지막 마디에 다시 카드 3 2 1 |
| 20.25~30초 (아웃트로) | 엔딩 반복 | 제목 + 빨간 '완주', 기록 6장을 손에 쥔 패처럼 부채꼴로(카드 왼쪽 위 모서리에 값, 총 거리 주황·달린시간 파랑·평균페이스 초록·심박수는 존 색), 뒤에 숨은 작은 JOKER 카드의 스타 러너, K♥ 카드에 러닝 메모(가민 줄바꿈 그대로) |

## 새 기록으로 만들 때
1. `prep_run.py`, `breaks.py`로 data.js / 캡처는 `cut_memo.py`로 메모를 잘라 `img/garmin.png`, `CAP.h` 확인 / 사진 `img/photo1.jpg` `img/photo2.jpg`
2. `RUN`(제목·메모·후기·사진 캡션) 수정
3. 노래가 같으면 `beat.js` `drums.js` 그대로. 바꾸면 `music_edit.py` → `drums.py`, 장면 시작 시각(`T1`~`T6`)은 `nearDB()`로 가장 가까운 마디 첫 박에 맞춰짐
4. `python3 scripts/fonts_b5.py .` → `node scripts/render.js video 60 out.mp4` → `python3 scripts/sfx_b5.py beat.js sfx.wav` → 노래와 섞어 합치기 (3안 README의 ffmpeg 명령과 같음)
