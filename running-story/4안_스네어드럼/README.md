# 4안 스네어 드럼 스테이지 (음악 편집 + 드럼 타격에 맞춘 진행)

노래 'Three Snare Cuts'는 드럼 비트 곡이고 스네어가 특히 강하다 (마디마다 킥 1번 + 스네어가 2·3·4박에 세 번). 그래서 화면 전체가 **실제 드럼 타격**에 반응한다.
검은 무대, 흰 글자, 스네어는 빨강. **스타 러너가 마칭 스네어를 직접 친다.** 내용 규칙은 1안과 같다 (가민 캡처 원본, 실제 페이스, 한글 라벨, 쉼표·마침표 없음, 메모 줄바꿈 유지, 심박수 존 색, 마지막 10초 반복, 1080×1920 60fps 30초).

## 소리와 타격 데이터
- 편집: `python3 -I scripts/music_edit.py 노래.wav music30.wav beat.js 0 3.228 17.02 42.5 58.8` (4마디 프레이즈 경계끼리, 이음새 13.79초)
- 타격: `python3 -I scripts/drums.py music30.wav beat.js drums.js` → 박마다 킥(35~130Hz)과 스네어(1.5~5kHz) 세기 + 소리가 끊기는 순간(cuts)
- 화면 반응 (모두 그 박의 실제 세기만큼):
  - 스네어: 스타 러너가 양손을 번갈아 스틱을 들었다가(센 타격일수록 높이) 박에 맞춰 헤드를 내리침 → 헤드 위 빨간 파문 + 충격파 링 + 흰 번쩍임 + 화면 흔들림
  - 킥: 화면 전체가 살짝 튀어나옴(줌 펌프)
  - 노래가 끊기는 순간(0.66 1.34 14.14 24.02 26.14초 등): 무대가 잠깐 어두워짐
  - 맨 아래 드럼 레인: 곡의 실제 킥(흰 막대, 위)과 스네어(빨간 막대, 아래)가 재생 위치를 지나 흐름
- 효과음: 노래가 곧 드럼이라 거의 넣지 않음. 캡처를 붙일 때와 셋리스트를 붙일 때 테이프 소리 두 번만 아주 작게 (`scripts/sfx_b4.py`)

## 구성

|---|---|---|
| 0~1.04초 (못갖춤마디) | 시작 | 스네어를 치는 큰 스타 러너, 박마다 '오늘의' '러닝'이 꽂힘 |
| 1.04~3.18초 | 제목 + 사진 | 첫 킥에 '회복조깅'. 이어지는 스네어 세 번에 오늘의 사진이 화면 가득 하드 컷(흑백 + 빨강): 사진1 → 사진2 → 두 장을 대각선으로 나눠서, 메모와 날짜 |
| 3.18~7.41초 | 가민 캡처 | 메모를 잘라낸 캡처를 **전체 그대로**(확대·덧그림 없음, 충격파도 캡처 뒤로). 스네어 세 번에 맞춰 왼쪽 빨간 테이프 '지도' '제목' '기록'이 하나씩 꽂힘 |

| 11.66~15.88초 | 페이스 그래프 | 실제 페이스(약 9초 이동평균)를 반 박자에 1km씩. 이음새(13.79초)에서 최고 페이스가 나온 km만 빨갛게 비추고 두 박자에 걸쳐 그림 → 최고 지점 + 빨간 테이프 카드 '마지막 1km 스퍼트 / 순간 최고 4'01" / 8km 구간 4'58"'이 장면 끝까지 |
| 15.88~20.13초 | 심박존별 시간 | 가민 순서(5존→존 미만) 존 색 막대가 **스네어를 칠 때마다 0에서 그 존의 최대치까지 솟았다 떨어짐**(계속 켜진 최대치 표시는 없음, 시간·%는 막대 옆에 고정), 평균·최대 심박수(존 색), 가장 오래 머문 존, 중간 멈춤 여부 |
| 20.13~30초 | 엔딩 반복 | 제목 '회복조깅' 아래 스네어를 치는 스타 러너(드럼 몸통에 '완주'), 기록 6칸, 무대 바닥에 테이프로 붙인 셋리스트에 러닝 메모(가민 줄바꿈 그대로) |

## 새 기록으로 만들 때
1. `prep_run.py`, `breaks.py`로 data.js / 캡처는 `cut_memo.py`로 메모를 잘라 `img/garmin.png`, `CAP.h` 확인 / 사진 `img/photo1.jpg` `img/photo2.jpg`
2. `RUN`(제목·메모·후기) 수정
3. 노래가 같으면 `beat.js` `drums.js` 그대로. 바꾸면 `music_edit.py` → `drums.py`
4. `python3 scripts/fonts_b4.py .` → `node scripts/render.js video 60 out.mp4` → `python3 scripts/sfx_b4.py beat.js sfx.wav` → 노래와 섞어 합치기 (3안 README의 ffmpeg 명령과 같음)

## 스타 러너 드러머 (`drummer3d.js`, 매 프레임 3D로 그림)
- 스킬의 스타 러너 3D 모델(GLB, `lib/`)에 3D 마칭 스네어(빨간 몸통, 크롬 후프, 러그와 텐션 로드, 흰 헤드, 스탠드)와 스틱 두 개를 붙여, 영상의 매 프레임마다 실제 자세로 렌더한다 (렌더할 때 WebGL이 필요해서 `scripts/render.js`는 SwiftShader 옵션으로 크로미움을 띄움)
- 동작 (`drumState()`): 모두 노래에서 잰 박자·스네어 타격 기준
  - 고개: 매 박마다 크게 끄덕임(아래로 숙였다가 박 사이에 들어 올림), 몸도 박에 맞춰 살짝 내려앉음, 좌우로 흔들
  - 스네어: 양손 번갈아, 칠 박 직전에 스틱을 들어 올렸다가(센 타격일수록, 흥이 오를수록 높이) 박에 맞춰 내리침, 헤드에 빨간 파문
  - 흥(`EXC`): 곡이 진행될수록 0.3 → 1로 올라가 끄덕임과 스윙이 점점 커짐
  - 점프 앤 슬램(`JUMPS`): 흥이 오르면 마디마다(처음엔 두 마디에 한 번) 마지막 센 스네어에 맞춰 웅크렸다 → 두 팔을 머리 위로 들고 높이 뛰었다가 → 두 스틱으로 세게 내리치며 착지. 이때 충격파·화면 흔들림·번쩍임이 평소의 두 배
- 장면마다: 시작은 크게, 데이터 장면은 제목 오른쪽에 작게, 엔딩은 가운데(점프해도 제목과 기록에 닿지 않게 위아래 여백을 둠)
- 드럼 몸통에는 글자를 쓰지 않는다 (손과 스틱에 가려짐). '완주'는 엔딩 제목 옆 빨간 테이프
