# 2안 도트 게임 스테이지 양식

오늘의 러닝을 8비트 게임 한 판으로 보여주는 양식. 내용 규칙은 1안과 같다 (가민 캡처 원본, 실제 페이스, 한글 라벨, 쉼표·마침표 없음, 메모 줄바꿈 유지, 심박수 존 색, 마지막 10초 반복, 1080×1920 60fps 30초).

| 시간 | 장면 |
|---|---|
| 0~4.8초 | 오프닝: 사진 모자이크 등장(사진마다 도트 스타 러너) → 픽셀 배경 → RECORD 게임 창에 가민 캡처, ▶ 커서가 지도·메모·기록을 짚음 |
| 4.8~9.6초 | 스테이지 맵: 실제 페이스가 지형(빠를수록 높음), 도트 러너가 달리고 km 깃발마다 코인, 구간 기록은 축 아래 한 줄, 순간 최고 별 |
| 9.6~14.4초 | 스테이터스: PLAYER·STATUS·SPLITS 창, 커서가 한 줄씩 |
| 14.4~18초 | 심박 게이지: 존별 10칸 게이지 + HR LOG 도트 막대, 멈춤 표시, 존 문구 |
| 18~20초 | STAGE CLEAR 팡파레·불꽃 |
| 20~30초 | 결과 화면 반복: 달리는 도트 러너, 기록 6칸, MEMO 대화창 |

- 글꼴: 숫자·영어 Press Start 2P, 한글 Noto Sans KR(각진 그림자)
- 효과음: `scripts/sfx_b2.py` 8비트 합성음, 피크 -15 dBFS (각 km 코인 시각은 `b2_times.json`)
- 새 기록: 1안과 같은 순서로 `prep_run.py`, `breaks.py` 실행 후 `story.html`의 `RUN`만 수정
