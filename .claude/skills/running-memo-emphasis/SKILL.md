# 러닝 메모 강조

러닝 스토리 영상의 엔딩(마지막 약 10초)에 나오는 러닝 메모를 그냥 한 줄씩 쓰지 않고, **중요한 부분을 골라 그 양식의 디자인으로 강조**한다. 5안 오로라에 처음 적용했고 6안 펑크 TV, 7안 힙합 골목, 8안 나이트 라이드, 9안 재즈 슬리브에도 적용했다 (`running-story/5안_오로라펄스/`).

## 지켜야 할 것 (기존 메모 규칙과 같음)
- 사용자가 쓴 **단어를 바꾸지 않는다**. 강조는 색·글꼴·크기·밑줄·띠로만
- 사용자가 가민에 쓴 **줄바꿈을 그대로** 지킨다. 한 줄이 상자보다 길 때만 글자를 먼저 줄이고, 그래도 넘치면 그 줄 안에서만 줄바꿈
- 쉼표·마침표를 새로 넣지 않는다 (숫자의 소수점은 예외)
- 한 줄에 강조는 1~2곳. 모든 줄을 다 강조하면 강조가 사라진다
- 강조가 들어가도 글자가 다른 요소에 가려지지 않는지 `running-story/qc.sh`의 확대 시트로 확인

## 무엇을 강조하나 (종류)
| 종류 | 고르는 것 | 예 (11/26 회복조깅 메모) |
|---|---|---|
| `num` | 거리·시간·횟수 등 숫자+단위 | `10km` `8km` |
| `body` | 몸 상태·통증·심박·호흡 | `근육통` `다리가 힘들어서` `심박수가 급상승` |
| `plan` | 다음 러닝·휴식·요일·시간대 | `하루 더 쉬고` `토요일 오전` |
| `feel` | 감정·기분 | `뿌듯` `상쾌` `아쉽` |
| `key` | 그 밖에 메모의 핵심 | (사용자가 강조해 달라고 한 말) |

- 메모의 **첫 줄은 머리글**로 조금 크게 (`headline`)
- 사람이 고르는 것이 가장 좋다: 메모를 읽고 의미가 통하는 구(句) 단위로 표시한다 (`근육통`만이 아니라 `다리가 힘들어서`처럼)
- 표시가 없으면 `memo_emphasis.js`의 규칙(숫자+단위, 몸·계획·감정 단어)이 자동으로 고른다

## 표시하는 법
`story.html`의 `RUN`에 원문(`review`)과 같은 내용에 `[[...]]`를 친 `reviewMarks`를 넣는다. 종류를 정하려면 `[[...|kind]]`.

```js
review:'10km 뛰려다가 8km까지만\n아직도 근육통이 심하다\n따뜻하게 입어서 그런지 다리가 힘들어서 그런지\n심박수가 급상승 해버렸다\n내일은 하루 더 쉬고 토요일 오전에 뛰어야지',
reviewMarks:'[[10km]] 뛰려다가 [[8km]]까지만\n아직도 [[근육통|body]]이 심하다\n따뜻하게 입어서 그런지 [[다리가 힘들어서|body]] 그런지\n[[심박수가 급상승|body]] 해버렸다\n내일은 [[하루 더 쉬고|plan]] [[토요일 오전|plan]]에 뛰어야지',
```
`[[ ]]`를 지운 글이 원문 줄과 다르면 그 줄은 자동 규칙으로 처리된다 (원문이 바뀌는 일을 막기 위해).

## 코드에 넣는 법
1. 이 폴더의 `memo_emphasis.js`를 양식 폴더에 복사하고 `story.html`에서 불러온다: `<script src="memo_emphasis.js"></script>`
2. 엔딩 장면에서:
```js
const lines=MemoEmphasis.parse(RUN.review,RUN.reviewMarks);      // [{tokens:[{text,kind}],headline}]
const mo=memoStyle();                                             // 양식마다 정의 (아래)
// 상자 폭에 맞는 글자 크기: 가장 긴 줄이 들어갈 때까지 px를 줄인다
for(let px=48;px>=34;px-=2){mo.px=px;if(lines.every(l=>MemoEmphasis.width(ctx,l,mo)<=boxW-120))break}
lines.forEach((ln,i)=>{const t1=start+BPER*.6*i;                   // 줄이 박자에 맞춰 차례로 나타나고
  mo.k=eo3(P(t,t1+.45,t1+1.05));                                    // 조금 뒤에 강조가 켜진다 (0→1)
  MemoEmphasis.drawLine(ctx,ln,centerX,top+i*lineH,mo)})
```
3. `memoStyle()`은 그 양식의 언어로 만든다: `{px, headScale, glow, k, font(px,kind), color(kind,k), decorate(ctx,kind,x,y,w,px,k)}`. `k`로 색이 기본색에서 강조색으로 바뀌고, 밑줄·띠가 왼쪽에서 오른쪽으로 그려지게 한다.

## 양식별 강조 디자인
| 양식 | 바탕 | num | body | plan | feel/key | 등장 |
|---|---|---|---|---|---|---|
| 5안 오로라 (적용됨) | 유리 카드, 손글씨 | 금색 Outfit 굵게 + 은은한 빛 | 분홍 + 물결 밑줄 빛 | 청록 반투명 둥근 띠 | 보라 점선 / 청록→보라 밑줄 | 부드럽게 떠오른 뒤 천천히 켜짐 (박자 펌핑 없음) |
| 1안 블루프린트 | 흰 메모 칸 | 주황 ACC 색 굵게 | 존 색 계열 빨강 + 손그림 밑줄 | 파랑 형광펜 띠 | 초록 동그라미 표시 | 연필로 그어지듯 |
| 2안 도트 게임 | 픽셀 창 | 노랑 픽셀 글자 | 빨강 픽셀 깜빡임 2번 | 민트 픽셀 상자 | 분홍 픽셀 하트 | 한 글자씩 타자 → 강조 칸이 '띵' 하고 켜짐 |
| 3안 LP바 | 라이너 노트 종이 | 호박색 진하게 | 버건디 손글씨 밑줄 | 형광 노랑 펜 띠 | 연필 동그라미 | 손글씨로 적히듯 |
| 6안 펑크 TV (적용됨) | 크림 카드, Gaegu 손글씨 | 주황 Shrikhand + 연한 주황 동그라미 | 빨강 물결 밑줄 | 머스터드 형광펜 띠 | 청록 동그라미 / 갈색 밑줄 | 박자마다 한 줄씩 튀어나오고 강조가 켜짐 |
| 7안 힙합 골목 (적용됨) | 어두운 상자, Nanum Pen 손글씨 | 노랑 Alfa Slab One + 연한 노랑 바탕 | 빨강 마커 밑줄 | 초록 반투명 띠 | 파랑 / 크림 밑줄 | 반 박마다 한 줄씩 올라오고 강조가 켜짐 (잔상 없음) |
| 8안 나이트 라이드 (적용됨) | 어두운 패널 + 호박색 테두리, Gowun Dodum | 호박색 Saira Condensed 굵게 + 연한 호박색 바탕 | 빨강 + 차선 같은 점선 밑줄 | 청록 반투명 띠 | 파랑 / 흰 밑줄 | 박마다 한 줄씩 아래에서 올라오고 강조가 켜짐 |
| 9안 재즈 슬리브 (적용됨) | 미색 해설지 카드, 고운바탕 명조 | 탠저린 Big Shoulders + 연한 탠저린 바탕 | 빨강 직선 밑줄 | 코발트 반투명 띠 | 코발트 두 줄 밑줄 / 핵심은 굵게 + 먹 밑줄 | 줄이 0.14초 간격으로 툭 나타나고 강조가 세 번 끊기며 켜짐 |
| 4안 스네어 드럼 | 셋리스트 종이 | 빨강 굵은 글자 | 검정 매직 밑줄 두 줄 | 빨간 테이프 조각 | 매직 동그라미 | 스네어 타격에 맞춰 강조가 '쾅' 하고 찍힘 |

양식의 원래 분위기를 따른다. 5안처럼 차분한 양식은 박자에 맞춰 튀지 않게, 4안처럼 타격이 중심인 양식은 실제 타격 시각에 맞춰 찍는다.

## 확인
- 렌더 후 `running-story/qc.sh <영상> <폴더> <메모 칸 crop> <엔딩 시작> 30` 으로 메모 칸을 원본 크기로 보고, 강조된 글자가 잘리거나 겹치지 않는지, 줄바꿈이 원문과 같은지, 쉼표·마침표가 새로 생기지 않았는지 확인
